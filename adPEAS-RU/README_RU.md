# adPEAS-RU 2.9.0

Русскоязычная адаптация [adPEAS v2](https://github.com/61106960/adPEAS)
для аудита безопасности Active Directory.

**Исходник:** `61106960/adPEAS`, версия 2.9.0, commit
`ee0c9c47cddcaddae74ef3b8a43f9fef1bf2d082`.

**Статус:** перевод основных элементов HTML, сравнения отчётов, части интерактивных
подсказок и сообщений консоли. Полный перевод всех технических описаний находок,
английской документации и каждого модуля **ещё не завершён**. Функциональность
исходного проекта сохранена, имена команд и структурированные ключи не переводились.

## Локализация содержимого отчётов (редакция 2026-11-10)

- 125 заголовков разделов и пояснений к проверкам переведены.
- Все 392 названия классов находок переведены.
- Для 141 находки подготовлены предметные русские описания, последствия и меры устранения.
- 280 названий полей и значений атрибутов представлены в русскоязычном справочнике.
- Локализованы 104 заголовка реальных проверок и 123 вхождения сообщений в 41 модульном файле.
- Перевод названий находок применяется также в основном HTML-представлении, без замены машинных идентификаторов.
- Для ещё не переведённых длинных технических объяснений выводится русская краткая аннотация; полный английский текст остаётся в раскрываемом разделе «Оригинал EN».

**Важно:** это существенно расширенная русификация отчётов, но не полный
построчный перевод всех 392 наборов технических объяснений и всей динамической
консольной выдачи. Содержание исходного JSON, идентификаторы FindingId,
названия прав и протоколов сохраняются.

Чтобы увидеть обновления, необходимо **создать новый HTML-отчёт**:
уже сохранённые отчёты от предыдущей сборки автоматически не изменяются.

## Полный перевод видимых заголовков карточек и прав Windows

Обновление 2026-11-10 для HTML-отчётов:

- 124 шаблона `TitleFormat` переведены непосредственно в модуле `adPEAS-ObjectTypes.ps1`. Это исправляет заголовки «Dangerous ACL» и «GPO User Right» вместе с другими объектами.
- Все 29 прав Windows (`SeDebugPrivilege`, `SeBackupPrivilege`, `SeAssignPrimaryTokenPrivilege` и др.) имеют русские отображаемые названия и русские описания влияния на безопасность.
- Переведены 79 динамических сообщений результатов аудита в 38 файлах проверок, включая численные сводки DCSync, ACL, GPO, сертификатов и учётных записей.
- Блок первоочередных мер, категории боковой панели и кнопки раскрытия карточек переведены без изменения `FindingId`, `Se*`, JSON, ACL или идентификаторов фильтрации.
- Приоритетные меры используют предметные русские рекомендации из словаря из 141 находки; для остальных выводится краткая русская рекомендация с возможностью открыть точное английское описание разработчика.

**Технические ограничения:** все динамические строки adPEAS ещё не переведены. Некоторые английские термины могут сохраняться в технических атрибутах и подробностях, особенно для находок без предметного русского описания. Точный оригинал EN сохранён для сверки. После обновления сборки требуется повторный запуск аудита: старые сохранённые HTML не изменяются.

## Русификация рекомендаций и команд (редакция 2026-11-11)

В HTML-отчёте локализованы **все 586 подписей к командам** из
`RemediationCommands.Description`. Перевод выполняется на этапе сборки,
по точному каталогу, а не через ненадёжную замену произвольных английских слов.

Дополнительно переведены **111 уникальных строк комментариев** внутри 52
многострочных блоков PowerShell, а также 47 типов однострочных
команд-подсказок. Внутренние команды вроде `Get-ADGroupMember`,
`Set-ADComputer`, GUID, атрибуты LDAP и параметры PowerShell оставлены
неизменными. Для примера команда «Вывести всех участников группы
„Администраторы домена“ (Domain Admins), включая вложенные группы» содержит
тот же `Get-ADGroupMember -Identity 'Domain Admins' -Recursive`, что и
оригинальная версия.

**Важно:** команды исправления (особенно `Remove-ADGroupMember`,
`Set-ADComputer`, `Set-ADAccountControl` и изменения AD CS) предназначены
для отдельной ручной проверки и выполнения уполномоченным администратором.
Они не запускаются автоматически при открытии HTML.

Группа `Protected Users` подходит для пользователей с проверенными
зависимостями аутентификации. Не добавляйте компьютерные или служебные
учётные записи в эту группу. Удаление RC4 и изменение параметров делегирования
может нарушить работу устаревших служб. Применяйте изменения сначала в
тестовой среде, с резервной копией и планом восстановления.

Оставшиеся исходные английские цитаты и технические пояснения доступны в
разделах «Оригинал EN»; перевод команд не изменяет юридические сведения
и исходную лицензию adPEAS.

## Запуск

Скачайте ветку `adpeas-ru-2.9.0` репозитория
`paruzelk/powershell` и откройте каталог `adPEAS-RU`.
В Windows PowerShell 5.1 выполните:

```powershell
.\Run-AD-Audit-RU.ps1 -Domain "stios.local" -OPSEC
```

Аудит отдельных разделов:

```powershell
.\Run-AD-Audit-RU.ps1 -Domain "stios.local" -Module Domain,Accounts,Rights,GPO -Format All -OPSEC
```

Результаты сохраняются в `Reports\AD-Audit-ГГГГММДД_ЧЧММСС.*` в TXT, HTML и JSON.
Для LDAPS сертификат контроллера домена проверяется по умолчанию.
При необходимости укажите `-Server dc01.stios.local`. Для другой учётной
записи — `-Credential (Get-Credential)`.

**Безопасность:** `-OPSEC` пропускает часть активных проверок, но не делает
полный аудит пассивным. Исходный adPEAS содержит функции, способные изменять
объекты домена; не выполняйте их без отдельного разрешения. Отчёты могут
содержать конфиденциальные сведения о вашей AD.

## Сборка и проверки

В репозитории сохранены `src`, `docs`, `license`, исходные
`Build-Release.ps1` / `Build-Engine.ps1` и четыре автономных варианта.
Для повторного импорта используется `Import-adPEAS-RU.ps1`. Он загружает
зафиксированный SHA GitHub-архива, проверяет Git blob SHA-1, применяет
локализацию, проверяет синтаксис PowerShell 5.1 и выполняет штатную сборку.

```powershell
.\Tests\Invoke-CI.ps1
```

В GitHub Actions также проверяется JavaScript через `node --check`.
Это структурные тесты, **не интеграционное тестирование на реальном домене**.
