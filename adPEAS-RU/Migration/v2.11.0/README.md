### Что исправлено по реальному HTML-отчёту MIG4

- Исходный HTML теперь сразу содержит русские заголовки девяти разделов и названия категорий.
- Счётчики карточек `result`/`item(s)` формируются по-русски в HTML, без ожидания выполнения JavaScript.
- Подписи объектов переводятся только по проверенным шаблонам; имена, SID, DNS, AD-атрибуты остаются нетронутыми.
- Подзаголовок `RODCPasswordReplication` переведён при формировании отчёта, а не только во всплывающей подсказке.
- Последняя полностью английская строка из категории Creds переведена по точному исходному вызову `Show-Line`.
- MIG4 runtime остаётся для дополнительных динамических надписей и доступности.
- Контроль Windows PowerShell 5.1, UTF-8 BOM и сохранения исходного каталога 408 проверок — обязателен.
- Сборка **не Production Ready**: проверка реальных HTML-файлов MIG5 впереди.


### MIG6 — исправления по реальному отчёту MIG5

- Проверено: девять русских заголовков, пятнадцать пунктов навигации и 78 из 78 счётчиков карточек выводятся по-русски до JS.
- В исходном HTML MIG5 обнаружено 16 полностью английских строк результатов. MIG6 переводит их через 9 фиксированных сообщений и 10 ограниченных регулярных выражений; также исправлены два смешанных сообщения настроек LDAP/GPO.
- В HTML-рендеринг атрибутов добавлены 12 статусов и 11 шаблонов единиц измерения; оригинальные значения и имена свойств не изменяются.
- Не изменять исходный HTML пользователя и не публиковать в репозитории данные `stios.local` из отчёта.
- Результаты проверок, команды устранения, лицензия и каталог находок остаются каноническими. MIG6 не подтверждён в рабочем AD.

# adPEAS-RU 2.11.0 — MIG1: миграция каталогов

## Исходное состояние

- Последняя сохранённая русская версия: DOC6j, `paruzelk/powershell`, ветка `adpeas-ru-2.9.0`, коммит `778d03e13c98bd357fe369b7300b1d59801e3f1e`.
- Оригинал 2.9.0: `61106960/adPEAS@ee0c9c47cddcaddae74ef3b8a43f9fef1bf2d082`.
- Новый оригинал 2.11.0: `61106960/adPEAS@477696f48d6b486be5d9a99b598f72e3ccfcc0c0`, тег `v2.11.0` от 17.11.2026.
- Старая ветка **не изменяется**; эта ветка содержит отдельно воспроизводимый путь перехода.

## Подтверждённый объём изменений

| Показатель | 2.9.0 | 2.11.0 |
|---|---:|---:|
| Типы находок | 392 | 408 |
| Типы разделов отчёта | 125 | 128 |
| Новые FindingId | — | 16 |
| Изменённые существующие определения | — | 63 |
| Удалённые FindingId | — | 0 |
| Новые типы разделов | — | 3 |

**Новые типы разделов:** `GPOLogonRestriction`, `GPOUserRightValue`, `ComputerInitialPassword`.

**MIG1 переводит:** 16 новых заголовков находок и их предметные краткие пояснения; три новых раздела с SectionTitle, Summary, WhyItMatters, WhatWeCheck и SecureMessage. Рабочий preview-процесс переносит неизменённые старые заголовки находок и тексты SectionTitle/Summary, только если исходный английский текст совпадает.

**MIG1 ещё не переводит:** полный текст новых Attack/Impact/Remediation, их инструменты и команды, изменённые 63 определения, полную документацию 2.11.0 и остальные новые сообщения в консоли. Ранее проверенные русские тексты для старых определений сохраняются в каталогах этой ветки и требуют сопоставления с новой исходной редакцией до применения.

## Строгие правила переноса

1. Не изменять FindingId, Risk, BaseScore, правила обнаружения, PowerShell-команды исправления, LDAP-атрибуты, схемы JSON и функционал безопасности.
2. Изменённые оригинальные технические тексты (63 FindingId) помечать `RequiresReview`; не применять старые Attack, Impact, Remediation без сверки EN↔RU.
3. На MIG1 русифицировать лишь слой отображения; оригинальный каталог `adPEAS-FindingDefinitions.ps1` из 2.11.0 не заменять старым.
4. Любое расхождение в числе определений или английских заголовках должно прерывать сборку, а не скрываться.
5. .ps1/.psm1/.psd1 в создаваемом preview должны иметь UTF-8 BOM. Проверить синтаксис в Windows PowerShell 5.1.
6. Тесты GitHub Actions — офлайн. Это **не** подтверждение работоспособности в реальном домене.
7. Лицензию оригинального проекта и условия автора сохранить.

## Как получить пробную сборку

Запуск `adPEAS RU 2.11.0 MIG1 - preview only` на новой ветке выполняет:

1. Загрузку обоих оригиналов по закреплённым SHA.
2. Проверку каталогов 392→408 и разделов 125→128.
3. Создание отдельной копии оригинала 2.11.0 с предварительным RU-слоем (старая база DOC6j не перезаписывается).
4. Проверку синтаксиса PowerShell и BOM.
5. Сборку четырёх вариантов с помощью оригинального `Build-Release.ps1`.
6. Публикацию **только при SUCCESS** артефакта `adPEAS-RU-2.11.0-MIG1-PREVIEW` с JSON-отчётом сопоставления.

Это **не production release** и не полноценная русификация. Для проверки содержимого используйте только тестовую среду; пока нет подтверждения корректности реального аудита AD.
