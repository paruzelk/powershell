## MIG21: реальные домены

Тестировать только домены, на аудит которых есть разрешение. Использовать Windows PowerShell 5.1, новую сессию на домен/режим, обычную учётную запись с достаточным доступом чтения, без передачи паролей в командной строке. Начать с OPSEC; он снижает активность, но не гарантирует пассивность. Full — отдельный согласованный запуск; Bloodhound создаёт чувствительный ZIP, хранить локально. Не выполнять команды исправления из отчёта в рамках испытаний.

Из каталога candidate:

~~~powershell
$domain = 'example.local'
$base = Join-Path (Get-Location) ('MIG20a-DomainA-OPSEC-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
Import-Module .\adPEAS.ps1 -Force
Invoke-adPEAS -Domain $domain -UseWindowsAuth -OPSEC -NoColor -Outputfile $base -Format All
Disconnect-adPEAS
~~~

В отдельной сессии при наличии разрешения на обычный аудит без OPSEC:

~~~powershell
$domain = 'example.local'
$base = Join-Path (Get-Location) ('MIG20a-DomainA-Full-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
Import-Module .\adPEAS.ps1 -Force
Invoke-adPEAS -Domain $domain -UseWindowsAuth -NoColor -Outputfile $base -Format All
Disconnect-adPEAS
~~~

При необходимости LDAPS с проверкой сертификата см. README-RU-2.11.0.md: Connect-adPEAS -UseLDAPS -IgnoreSSLErrors:$false, затем Invoke-adPEAS без нового подключения. Имена DomainA/DomainB и выходные пути уникальны; результаты разных доменов не объединять. Проверить завершённость, CompletedModules, FindingCount, наличие HTML/TXT/JSON, отсутствие ошибок и визуальную русификацию. Числа между доменами не обязаны совпадать. Сначала передать обезличенную сводку, версии ОС/DC, режим, ошибки и оставшиеся английские фразы. Исходные отчёты содержат конфиденциальные сведения AD, учётные данные могут присутствовать в находках: не публиковать в GitHub и не отправлять без проверки/разрешения. Не передавать BloodHound ZIP. Реальные испытания не выполнены в CI. ProductionReady=False.
