## Результаты CI

В PREVIEW/COVERAGE: 2.11.0-mig20-source.json, 2.11.0-mig20-ast.json, 2.11.0-mig20-runtime.json. Они содержат только исходный код и синтетические данные. PASS означает успешное построение инвентаря и проверки инвариантов, НЕ 100% перевод. Классы *review* — кандидаты на ручное изучение, включая технические имена/параметры и смешанные фразы. Динамический текст, произвольные значения AD, JavaScript и справка с непрямым формированием не могут быть полностью доказаны эвристикой/AST. Не следует переводить команды, идентификаторы, данные AD или английские оригинальные определения без проверки назначения.

Следующее решение принимается по содержанию карт: при наличии пользовательских непереведённых фраз — точечный этап MIG20a; если остаток обоснованно закрыт — MIG21 (другие реальные домены). ProductionReady=False. Новые отчёты сейчас не требуются; при необходимости локальную приёмку можно повторить неизменным Invoke-MIG19k2LocalAcceptance.ps1.
