# MIG21a — конфликт SIDBytes и происхождение текста

База: MIG20a, CI 45956635104 PASS. Реальные тесты на четырёх доменах: 8 комплектов, ошибки SIDBytes в одном домене в обоих режимах, в Full также в Collector. Ошибки аутентификации из предыдущих попыток исключены из дефектов по уточнению оператора. Недоступность SYSVOL и Complete при частичных ошибках — отдельная задача MIG21b. Реальные данные не публикуются.

## Причина и исправление

В закреплённом оригинале 2.11.0 (477696f48d6b486be5d9a99b598f72e3ccfcc0c0) определены Convert-SIDToString с [byte[]] SIDBytes (Core/ConvertFrom-LDAPAttribute.ps1) и Convert-SidToString с SidInput (Collector/Invoke-adPEASCollector.ps1). PowerShell сравнивает имена без учёта регистра. После сборки второе определение перекрывает первое, что приводит к ошибке именованного параметра в sIDHistory и трёх tokenGroups. В опубликованном MIG20a обе функции присутствовали (SHA-256 архива eb2059315ccb0076cb3403675cd8b6b5be87c30d8b33cbf0d488756ef8ed9074, CRC PASS). Исправление: только два точных идентификатора в Core, новое уникальное имя Convert-LdapSidBytesToString. Collector, алгоритмы, формат SID, классификация находок и переводы не меняются. Обратимость на уровне байтов и отсутствие иных правок PS1 проверяются.

Тест в каждой собранной PS1/EXE: фактический ConvertFrom-LDAPAttribute на четырёх SID-атрибутах, одиночный byte[], смешанные значения, строка, недействительные байты, null; сохранение порядка и типа; исходный интерфейс Collector на строке, объекте SecurityIdentifier и byte[]. Маркер MIG21A_LDAP_SID_COLLISION_OK обязателен в пяти независимых процессах, прежние регрессии сохраняются. Без LDAP и реальных данных.

## Откуда берётся английский текст

2.11.0-mig21a-text-origin.json — исходные места для выбранных безопасных фраз из отчётов, без реальных значений AD. Не найдено в исходниках не означает автоматически «данные AD»: возможны динамическая сборка, внешние библиотеки, локаль ОС и исключения. Пример Unchanged, never used формирует проверка компьютеров, а шаблон Severity использует его для оценки: перевод только на слое представления. Имена LDAP, DN, SID, группы, значения description, имена GPO и пути поступают из домена; оставлять оригинал. Названия атрибутов локализовать только в HTML/TXT. Статусы, generated labels и диагностику проверять на потребителей перед переводом. MIG21c — отдельный этап локализации, без изменения логики. Не публиковать реальные отчёты, имена доменов и содержимое находок.

## Приёмка
