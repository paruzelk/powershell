# MIG19a3

MIG19a2 (45605272242): исходники локализации, синтаксис, все пять сборок и ресурс EXE прошли проверку. Runtime остановился на пустом ExitCode и отсутствии подтверждения первого варианта; точная причина не установлена. MIG19a3 сохраняет Build-MIG19a2.py без изменений, заменяет Start-Process на Python subprocess.run с отдельными argv, абсолютными путями, stdout/stderr, таймаутом и фактическим кодом процесса. Probe записывает этапы и UTF-8 JSON. Проверяются все пять вариантов, а не только первый. Самотест тестирует код 0/7, stderr, таймаут, отсутствие/повреждение JSON и маркер. Отдельный диагностический артефакт загружается даже при FAIL; релизный ZIP только при PASS. AD не вызывается. Повторное использование успешной локализации не отменяет обязательные проверки безопасности. Реальный результат Windows CI пока не подтверждён.
