# MIG19f — исправления отображения по реальному MIG19e

Основание: два успешных реальных аудита (OPSEC и Full), все три формата, Complete=True, 231/244 записи JSON, 78/80 карточек HTML. Предыдущий CI 45811803998 PASS. Реальные отчёты и данные домена не включаются в репозиторий.

В MIG19f использованы шесть обратимых точечных изменений в двух исходных файлах: дополнительные заголовки/строки в существующих русских HTML-словарях, переиспользование словаря при выводе Show-Output после Add-Finding, два отображаемых ключа и узкие шаблоны служебных сообщений подключения, длительности и путей сохранения. JSON и объекты не переводятся этой правкой; технические идентификаторы и значения сохранены. Тест десяти синтетических отображаемых сообщений и двух фактических вызовов Show-Output в пяти вариантах добавлен к существующим регрессионным тестам. Дополнен README про BloodHound. Карта остаточных кандидатов d7 не обновляется этим presentation-only патчем; остаточные подписи и значения атрибутов, другая справка, консольные сообщения вне Show-Output и браузерная динамика требуют отдельной проверки. PREVIEW, не RELEASE.
