## Реальная приёмка после CI SUCCESS

Только в доменах с разрешением на аудит. На каждом из четырёх доменов, в отдельных свежих сеансах Windows PowerShell 5.1, без повторного использования старого JSON. Сначала OPSEC, затем Full при наличии отдельного разрешения. Сохранять уникальные имена отчётов. Пример из папки candidate:

~~~powershell
$domain = 'example.local'
$base = Join-Path (Get-Location) ('MIG22-DomainA-OPSEC-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
Import-Module .\adPEAS.ps1 -Force
Invoke-adPEAS -Domain $domain -UseWindowsAuth -OPSEC -NoColor -Outputfile $base -Format All
Disconnect-adPEAS
~~~

Для Full открыть новую сессию, заменить OPSEC в имени на Full и убрать -OPSEC. Full может создавать чувствительный BloodHound ZIP — хранить локально, не передавать. Не выполнять команды исправления. При необходимости LDAPS использовать Connect-adPEAS -UseLDAPS -IgnoreSSLErrors:$false согласно основному README.

Приёмка: HTML/TXT/JSON каждого запуска, отсутствие SIDBytes, отсутствие необъяснённых ошибок, честная индикация неполноты, сохранение исходных значений и идентификаторов, визуальный контроль карточек. Complete=True означает экспорт, не успех всех проверок. Сравнивать с прошлыми результатами по смыслу; численное совпадение не обязательно. Перед передачей удалить конфиденциальные сведения.
