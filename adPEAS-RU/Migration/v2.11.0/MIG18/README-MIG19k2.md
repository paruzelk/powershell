# MIG19k2 — автономное формирование отчётов без ложной диагностики SID

База MIG19k1: CI 45842174633 SUCCESS, локальная приёмка PASS: OPSEC/Full 231/244 записей, 78/80 карточек, 631/701 атрибутов, 0 изменённых записей, 0 исключений. Реальные отчёты не публикуются.

В закреплённом оригинале 2.11.0 (477696f4) преобразователи memberOf, member, sIDHistory и Test-IsPrivileged вызывают ConvertTo-SID/ConvertFrom-SID при повторном рендеринге. Без LDAP исходные функции возвращают null/SID, но Show-NoSessionError добавляет диагностику к TXT. MIG19k2 добавляет внутренний признак в уже существующий временный LDAPContext конвертера и ограничивает подавление только этими двумя ожидаемыми диагностическими вызовами при отсутствии LDAP. Исходное finally восстанавливает предыдущий контекст. Прямые вызовы без подключения предупреждают как ранее; при наличии соединения ветви разрешения не меняются. Не используются текущие AD/Windows-кэши для новых догадок, не изобретаются имена или SID. Это не улучшение полноты разрешения неизвестных SID и не сертификат корректности пересчёта всех атрибутов на других доменах. Конвертацию выполнять в свежем сеансе без подключения; случай активного LDAP не переработан.

Три обратимые source-правки, прежние gates сохранены. Новый отдельный синтетический кэш с memberOf и sIDHistory, публичная конвертация All, проверка исходного SID, имён, отсутствия диагностики в TXT и консоли, неизменности входа/JSON, сохранения прямой диагностики и fallback до и после вызова. Исполнение на пяти вариантах. ProductionReady=False.

## Локальная приёмка

Windows PowerShell 5.1, новая сессия, из корня распакованного PREVIEW; использовать исходные JSON MIG19i:

~~~powershell
.\Invoke-MIG19k2LocalAcceptance.ps1 -SelfTest
.\Invoke-MIG19k2LocalAcceptance.ps1 -OpsecJson '.\AD-Audit-MIG19i-OPSEC.json' -FullJson '.\AD-Audit-MIG19i-Full.json'
~~~

Отправить MIG19k2-acceptance.json; проверить чувствительные пути и сообщения перед отправкой. Ожидается PASS, 0 изменённых записей, 0 SidSessionDiagnostics, прежние карточки, атрибуты и сводки. Новое сканирование AD не требуется. MIG19k3/MIG20 только после подтверждения локальной приёмки.
