# MIG19a1

Перевод стартового экрана, легенды, статических заголовков Get-adPEASHelp и отображаемого уведомления о лицензии. Не меняются проверки лицензии, параметры, имена команд и исходный текст дисклеймера. Полный каталог справки и прочие консольные сообщения требуют дальнейшего аудита. Тест отдельных процессов требует JSON-свидетельство после загрузки, совпадение публичных параметров и русский QuickStart; ExitCode 0 без свидетельства не считается успехом. AD не вызывается. Статус подтверждается только CI.
