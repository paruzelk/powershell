# MIG19b–c: офлайн-отчёты и эквивалентность вариантов

Контрольная сборка MIG19a4: CI 45608014266 PASS, пять вариантов, включая EXE. Исходники утилиты не меняются. Используется публичный Convert-adPEASReport -Format All -NoColor и единый искусственный JSON cache v1. Домен fixture.invalid; 11 записей, 4 карточки, 2 объекта; ожидаемые количества Finding=2, Hint=1, Note=1, Secure=1. Ни одного реального объекта, LDAP-вызова или аудита домена. Варианты запускаются изолированно. Сверяется возврат JSON с исходным fixture (исключается только ExportDate, timestamp приводится к моменту времени), текст, карточки/счётчики HTML, все 7 JS-каталогов и scoringContext. Случайные идентификаторы карточек и объектов нормализуются по месту появления, не меняя содержание. Node проверяет фактический JS отчёта. Прочие расхождения не маскируются. Синтетические отчёты и логи публикуются отдельным артефактом даже при FAIL. Preview только после зелёного CI. Ограничение: это проверка офлайн-конвертации, не доказательство равенства живого сканирования и не полный аудит всех 408 находок. Windows CI ещё не выполнен.
