# MIG19a4

MIG19a3 (45606659982): PS1/MIN/ULTRA/OBF полностью прошли runtime-проверки. EXE загрузился, но вызов Get-adPEASHelp из внешнего сценария завершился InvokeMethodOnNull в Get-ClassPrefix (строка 197, `$Script:ClassPrefixes.ContainsKey($Class)`). Предполагаемая причина — исходный dot-source ScriptBlock в глобальной области, не обеспечивающий постоянный script scope при вызове из другого PS1.

MIG19a4 меняет только загрузочную строку C# и её комментарий в Build-Engine.ps1, с точным SHA-256 предыдущего патча и обратимостью. Встроенный PS1 загружается напрямую в динамический модуль adPEAS; функции импортируются в глобальную область, `$Script:` состояние принадлежит модулю. Не создаётся временный файл payload. Параметры -Command/-c, интерактивный режим, лицензия, версия и содержимое PS1 не меняются. Новый тест сохраняет ранее обязательные проверки, добавляет принадлежность четырёх функций к одному модулю, значения ClassPrefixes/ANSI/версии/списка модулей и отдельный прямой вызов EXE -Command. Тесты не подключаются к AD. Точный результат исправления подтвердит Windows CI; интерактивный режим ещё не испытан вручную.
