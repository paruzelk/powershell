## Локальный запуск Windows PowerShell 5.1

Распаковать новый PREVIEW. Использовать исходные JSON MIG19i, а не повторно экспортированные MIG19k. В свежем сеансе PowerShell из корня архива:

~~~powershell
.\Invoke-MIG19k1LocalAcceptance.ps1 -SelfTest
.\Invoke-MIG19k1LocalAcceptance.ps1 -OpsecJson 'C:\Reports\AD-Audit-MIG19i-OPSEC.json' -FullJson 'C:\Reports\AD-Audit-MIG19i-Full.json'
~~~

Каталог создаётся автоматически. Отправить MIG19k1-acceptance.json (локально проверить чувствительные пути и сообщения); при REVIEW сообщить Stage, Message, FullyQualifiedErrorId, ScriptLineNumber и ScriptStackTrace. Полный JSON/HTML/TXT сохранять локально. Новое сканирование AD не требуется. Проверка SHA-256 входов, точного содержания находок, метаданных, HTML и TXT не ослаблена. CI исполняет SelfTest на Windows PowerShell 5.1 до сборки; 1 положительный и 5 отрицательных синтетических случаев. Все прежние тесты пяти вариантов и scope-метаданных остаются.

MIG19k1 не меняет исходник конвертера и не устраняет многочисленные сообщения ConvertTo-SID/ConvertFrom-SID без активного сеанса в автономном TXT. Этот дефект зарезервирован для MIG19k2; PASS данной приёмки не является подтверждением его исправления. ProductionReady=False. MIG20 только после закрытия обеих проблем и повторной приёмки.
