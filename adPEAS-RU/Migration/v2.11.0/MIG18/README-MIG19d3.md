# MIG19d3 — диагностика HTTP и подключения

База: успешный CI 45625784485 (MIG19d2b). Контрольная карта residual: 3169 кандидатов вывода, 862 кандидата synopsis; архив сверён с SHA-256 GitHub. Для этой партии выбрана диагностика HTTP/TLS, Exchange, AD CS и подключения вместо функций изменения объектов. Подготовлены 146 уникальных фраз / 153 вхождения: Invoke-HTTPRequest (124/128), Connect-adPEAS (14/16), Get-adPEASSession (8/9). Точные целые строки из закреплённого upstream; допускаются только Write-Log, Show-Line, Show-SubHeader, неизменные параметры вызова и переменные, идентификатор источника журнала и обратимость. CI проверяет количество вхождений в текущем кандидате; при расхождении прекращает сборку, не изменяя файлы. Сохраняются старые gates, включая изолированную справку и восемь runtime Get-Help, 15 отчётов, 10 пар. Карта остаточных кандидатов пересчитывается после патча и публикуется независимо от runtime. Составные строки, изменившиеся сообщения, остальная справка и другие модули отложены. Перевод вывода не является подтверждением поведения при реальном AD/HTTP-подключении; CI не выполняет сетевой аудит. Это частичная локализация, а не финальный релиз.
