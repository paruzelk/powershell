# Архитектура проекта

Исходная структура состоит из `src/adPEAS.ps1` и модулей под `src/modules/`. Отдельные уровни обслуживают LDAP-доступ, проверки, модель представления результатов и экспорт.

HTML-отчёт собирается из `report-template.html`, `report-styles.css` и `report-scripts.js`. Самостоятельный `Build-Release.ps1` встраивает эти ресурсы в автономный `adPEAS.ps1` и формирует дополнительные варианты `min`, `ultra`, `obf`.

Локализация не должна изменять `data-severity`, ID карточек, категории, имена функций JS, структуру JSON и LDAP-запросы. Компиляция PowerShell и проверка JavaScript выполняются в GitHub Actions.
