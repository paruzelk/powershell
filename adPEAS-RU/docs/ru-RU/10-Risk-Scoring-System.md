# Оценка риска и интерпретация результатов

Отчёт различает категории `Finding` (нарушение), `Hint` (предупреждение), `Note` (сведения) и `Secure` (безопасная конфигурация). Машинные значения категорий сохраняются на английском, русифицированы только интерфейсные подписи.

Оценка риска помогает ранжировать найденные проблемы, но не равна подтверждённому компрометированию. Приоритизируйте случаи с контролем привилегированных объектов, DCSync, некорректными шаблонами AD CS, чрезмерными правами GPO и слабым управлением учётными данными.

Для каждой находки фиксируйте владельца, описание доказательств, риск, запланированное исправление и результаты повторного сканирования.
