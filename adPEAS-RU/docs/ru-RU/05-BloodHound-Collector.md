# Коллектор BloodHound

Коллектор BloodHound CE собирает сведения об объектах AD, группах, правах и связях, чтобы исследовать цепочки потенциального повышения привилегий.

Для стандартного аудита без этой функции:

```powershell
.\Run-AD-Audit-RU.ps1 -Domain "example.local" -ExcludeModule Bloodhound -OPSEC
```

При необходимости полноценного экспорта заранее согласуйте объём сбора: большие домены могут создавать заметную нагрузку на LDAP. Не загружайте выходные ZIP/JSON на публичные сервисы. Рекомендовано хранить результаты в ограниченном каталоге, применять шифрование и удалять промежуточные файлы по принятой политике.
