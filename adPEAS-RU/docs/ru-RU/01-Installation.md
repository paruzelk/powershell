# Установка и подготовка

Поддерживаются Windows 10/11, Windows Server 2016–2025, **Windows PowerShell 5.1** и .NET Framework. Для базовой работы не требуются RSAT и модуль ActiveDirectory.

Скачайте ветку `adpeas-ru-2.9.0` из репозитория `paruzelk/powershell`; откройте каталог `adPEAS-RU`, содержащий `Run-AD-Audit-RU.ps1` и готовый `adPEAS.ps1`.

Команда в Windows PowerShell 5.1:

```powershell
.\Run-AD-Audit-RU.ps1 -Domain "example.local" -OPSEC
```

Для проверки LDAPS используйте FQDN контроллера домена и сертификат, выданный доверенным УЦ. По умолчанию наша обёртка **не игнорирует ошибки сертификата**.

Не запускайте исходные команды, меняющие AD, в продуктивной среде без отдельного разрешения. Результаты аудита содержат чувствительные сведения.
