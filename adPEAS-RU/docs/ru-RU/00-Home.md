## Что такое adPEAS

**adPEAS (Active Directory Privilege Escalation Awesome Scripts)** —
средство оценки безопасности на PowerShell, позволяющее обнаруживать
ошибочные конфигурации, уязвимости и возможные пути повышения привилегий
в доменах Active Directory.

### Ключевые особенности

- **Без внешних зависимостей:** используются встроенные классы
  .NET Framework (включая `System.DirectoryServices.Protocols`).
- **RSAT не требуется:** инструмент работает без модуля
  `ActiveDirectory` и Remote Server Administration Tools.
- **Автономная сборка:** достаточно одного файла `.ps1`.
- **Разные способы аутентификации:** Windows, учётные данные,
  сертификаты (PKINIT и Pass-the-Cert/Schannel), NT-хеши,
  AES-ключи и билеты Kerberos.
- **Приоритет Kerberos:** по умолчанию система сначала пытается
  использовать Kerberos, затем предусмотренные альтернативы.
- **Широкий набор проверок:** домен, права ACL, учетные записи,
  делегирование, AD CS, GPO, настройки компьютеров, приложения.
- **BloodHound CE:** встроенный сборщик для анализа путей атак.
- **OPSEC:** дополнительный режим, исключающий определённые
  активные проверки (Kerberoasting, AS-REP Roasting, BloodHound).
  Он не делает весь аудит абсолютно пассивным.

### Сценарии использования

- Тестирование на проникновение **с письменным разрешением**.
- Внутренний аудит безопасности AD.
- Уполномоченные Red Team-оценки.

## Версия и требования

- **Текущая закреплённая исходная версия:** adPEAS **2.9.0**
  (английская страница `docs/00-Home.md` всё ещё упоминает
  устаревшую цифру `2.0.0`; эта информация исправлена здесь).
- **PowerShell:** Windows PowerShell 5.1 или совместимая среда.
- **ОС:** Windows 10/11, Windows Server 2016/2019/2022/2025.

### Варианты поставки

| Вариант | Файл | Особенности |
|---|---|---|
| Читаемый | `adPEAS.ps1` | Полный код и комментарии |
| Минимизированный | `adPEAS_min.ps1` | Убраны комментарии |
| Сжатый | `adPEAS_ultra.ps1` | Максимальное сжатие |
| Обфусцированный | `adPEAS_obf.ps1` | GZip + XOR + Base64 |

## Юридические условия и авторство

**Применяйте adPEAS только в системах, где у вас есть разрешение
на проведение аудита.** Не выполняйте действия против чужих сетей
без соответствующих полномочий. Соблюдайте применимое законодательство
и договорные условия, храните отчёты как чувствительную информацию.

Программное обеспечение распространяется на условиях
**source-available**. Условия коммерческого использования приведены
в [лицензии](../../license/LICENSE.md); это не MIT/GPL.
