# Разделы проверки безопасности

`Invoke-adPEAS` поддерживает включение через `-Module` и исключение через `-ExcludeModule` следующих разделов:

| Модуль | Область |
|---|---|
| Domain | Конфигурация домена и доверий, LDAP/SMB и парольная политика |
| Creds | Риски раскрытия учётных данных, Kerberoast и AS-REP |
| Rights | ACL, делегированные права, DCSync и опасные разрешения |
| Delegation | Неограниченное, ограниченное и ресурсное делегирование |
| ADCS | Шаблоны сертификатов, удостоверяющие центры и пути ESC |
| Accounts | Привилегированные учётные записи и группы |
| GPO | Групповые политики и права их изменения |
| Computer | Конфигурация компьютеров, LAPS, устаревшие ОС |
| Application | Exchange, SCCM, SCOM |
| Shares | Общие ресурсы и разрешения |
| Bloodhound | Сбор графа отношений и полномочий |

Пример:

```powershell
.\Run-AD-Audit-RU.ps1 -Domain "example.local" -Module Domain,Rights,Accounts -OPSEC
```

Трактуйте результат как индикатор для проверки администратором, а не как доказательство эксплуатации. При неполных проверках отчёт должен отдельно указывать ограничения.
