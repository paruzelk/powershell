# Изменяющие функции Set- / New- / Move-

В исходном adPEAS присутствуют команды управления объектами каталога: `Set-DomainUser`, `Set-DomainGroup`, `Set-DomainComputer`, `Set-DomainGPO`, `Set-CertificateTemplate`, `New-DomainUser`, `New-DomainGroup`, `Move-DomainObject` и другие.

**Эти функции не относятся к пассивному аудиту.** Их нельзя запускать автоматически при обычной оценке AD. Для изменения объектов нужны отдельные права, резервная копия, перечень операций, согласованное окно обслуживания и план отката.

Русская обёртка `Run-AD-Audit-RU.ps1` не вызывает команды изменения объектов. Она подключается, выполняет проверки, сохраняет результаты и отключается.
