# ShareAudit

PowerShell-скрипт формирует HTML-отчёт по правам SMB-шар и ACL каталогов. По умолчанию он сканирует файловые SMB-шары локального сервера. Параметр `-Drives` ограничивает сканирование указанными каталогами, дисками или UNC-путями.

## Требования

- Windows PowerShell 5.1 или PowerShell 7 в Windows.
- Для режима SMB-шар нужен модуль `SmbShare` и права на чтение конфигурации шар.
- Для раскрытия AD-групп нужен модуль `ActiveDirectory` и доступ к контроллеру домена. Если модуль отсутствует, отчёт всё равно строится без участников групп и с предупреждением.
- Для полного отчёта нужны права на чтение ACL всех проверяемых каталогов.

## Запуск

```powershell
.\shareaudit.ps1 -OutputPath 'C:\Reports\shares.html'
.\shareaudit.ps1 -Drives @('C:\Data', '\\server\share') -OutputPath 'C:\Reports\folders.html' -ResolveGroups $false
.\shareaudit.ps1 -Drives @('D:') -MaxDepth 2 -OnlyExplicitAcl $false
```

Каталог для `-OutputPath` должен существовать. `-MaxDepth 0` проверяет только корень. По умолчанию глубина равна 5, а отчёт показывает только каталоги с явными ACE. `-ScanSubfolders $false` отключает обход подпапок. Все учётные записи, включая `Everyone`, отображаются по умолчанию; для сокращённого отчёта можно указать `-IncludeSystemAccounts $false`.

В режиме `-Drives` права SMB-шары не запрашиваются даже для UNC-пути: отчёт включает только ACL каталога. В режиме без `-Drives` выводятся права SMB и NTFS.

Отчёт перечисляет записи доступа, а не рассчитывает эффективные права пользователя. Наследуемые ACE скрыты при значении `-OnlyExplicitAcl $true`. Точки повторного анализа файловой системы (например, junction) при обходе подпапок пропускаются. Ошибки чтения ACL и состава групп выводятся в консоль и в раздел предупреждений HTML. Для групп из другого леса раскрытие участников зависит от доступности AD Web Services и доверительных отношений.

## Проверка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-Report.ps1
pwsh.exe -NoProfile -File .\tests\Test-Report.ps1
```

Проверка использует временный каталог внутри `tests` и локальные имитации ACL/AD; соединение с рабочим доменом не требуется.
