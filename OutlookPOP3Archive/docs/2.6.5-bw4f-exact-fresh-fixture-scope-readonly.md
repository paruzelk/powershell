# 2.6.5-BW4f — exact operator disposable fixture scope (read-only DEV)

## Purpose

BW4e2 allows an explicitly pinned fresh candidate in large Inbox
(26,485+ mails) to be read with exact Outlook Items.Restrict and no
full folder enumeration. BW4e2 does NOT determine whether that email
is a real customer's mail or a purposely created disposable fixture.

BW4f requires all previous BW4a/BW4b/BW4c/BW4d/BW4e2 read-only and
historical evidence gates, and additionally checks the actual two
Outlook read paths for the exact operator fixture marker:

    Subject: OPA265 BW4e1 FRESH TEST <lowercase GUID>
    Body contains: OPA265 BW4e1 disposable synthetic test.
    Body contains exactly one line: TestId: <same GUID>
    Outlook MailItem.Attachments.Count == 0

Both direct GetItemFromID and second Items.Restrict readback must agree
about the exact operator TestId and fixture classification. Any real
mail, missing marker, differing GUID, duplicate TestId, attachment,
unavailable attachment count, invalid historical pin or missing
targeted BW4e2 route is BLOCKED.

Matching a Subject/Body marker is not independent external evidence,
and an operator could forge an identically shaped message. Thus even
a perfect scope match returns exactly:

    DisposableFixtureScopeConsistentButNoMovePermit

All statuses preserve:
- original BW3a single unresolved Intent and seven immutable hashes;
- LIVE3/LIVE4 journal snapshots unchanged;
- HistoryCatalogComplete=False;
- CandidateNewnessIndependentlyProven=False;
- WorkerDispatchAllowed=False; CanInvokeMailMove=False;
- CanRetryPreviousMove=False; AutomaticRetryAllowed=False;
- ProductionReady=False;
- no new PST, no MailItem.Move, no new claim, no journal write.

BW4f is an additive DEV step, not the stable 2.5.7-FIX13b
yearly 90GB operator build. It does not modify that release branch.

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

Select the fresh test email in Outlook and prepare the exact BW4e2
parameter hashtable and $pin from the prior BW4e2 procedure.
BW4e2 targeted read-only scan must already have passed, including
matching MAPI InternetMessageId, SearchKeySha256, ContentFieldFingerprintSha256
and TargetedMessageIdReadOnlyUsed=True.

    $common.WorkerPilotUseTargetedMessageIdReadOnly = $true
    $testId = '98bef817-0fb5-478a-b869-33f02fda59d3'
    $reviewId = [guid]::NewGuid().ToString('D')
    .\OutlookPOP3Archive.ps1 @common -WorkerPilotReviewFreshFixtureScope -WorkerPilotCandidateReviewId $reviewId -WorkerPilotExpectedCandidateInternetMessageId $pin.InternetMessageId -WorkerPilotExpectedCandidateSearchKeySha256 $pin.SearchKeySha256 -WorkerPilotExpectedCandidateContentFingerprintSha256 $pin.ContentFieldFingerprintSha256 -WorkerPilotExpectedFreshTestId $testId | Format-List
