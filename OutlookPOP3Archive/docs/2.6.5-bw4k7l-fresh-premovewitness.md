## Prepare a completely new fixture

1. Open Outlook under profile Outlook; identify the actual POP3 Inbox in its correct delivery PST. Do not use IMAP, old historic Attachment1K or any previous five fixture messages.
2. Generate a fresh lowercase GUID, then send a benign NEW email to this POP3 account and download it into the Inbox. Exact subject is OPA265-BW4k7l-<guid>. The Body must contain OPA265-BW4k7l disposable fixture <guid>. Include exactly one by-value attachment containing 1024 bytes; use a simple ASCII filename. PR_INTERNET_MESSAGE_ID and PR_SEARCH_KEY must exist.
3. In Outlook, File > Account Settings > Data Files > Add, create an entirely new test PST named OPA265-BW4k7l-<guid>.pst, then create an empty immediate child folder OPA265-BW4k7l-<guid>. Do not reuse old Archives.
4. Select EXACTLY ONE newly arrived message in the POP3 Inbox. Prevent selection from changing the read flag while the two pre-Move samples are read. Do not drag or Move it.

Optional PowerShell code to generate deterministic 1024-byte payload for manual email attachment:

~~~powershell
$id = [guid]::NewGuid().ToString('D').ToLowerInvariant()
$bytes = New-Object byte[] 1024
for($i=0; $i -lt 1024; $i++){ $bytes[$i] = [byte]($i % 251) }
$attachmentPath = Join-Path $env:TEMP ('OPA265-BW4k7l-'+$id+'.bin')
[IO.File]::WriteAllBytes($attachmentPath,$bytes)
"Subject: OPA265-BW4k7l-$id"
"Body: OPA265-BW4k7l disposable fixture $id"
"Attachment: $attachmentPath"
~~~

## Determine exact destination folder EntryID

~~~powershell
$source='C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst'
$dest=Join-Path (Split-Path -Parent $source) ('OPA265-BW4k7l-'+$id+'.pst')
$app=[Runtime.InteropServices.Marshal]::GetActiveObject('Outlook.Application')
$ns=$app.GetNamespace('MAPI')
$stores=@()
for($i=1;$i -le [int]$ns.Stores.Count;$i++){
    $s=$ns.Stores.Item($i)
    if($s.FilePath -and [string]::Equals(
        [IO.Path]::GetFullPath([string]$s.FilePath),
        [IO.Path]::GetFullPath($dest),
        [StringComparison]::OrdinalIgnoreCase)){$stores+=,$s}
}
if($stores.Count -ne 1){throw 'Fresh target PST not uniquely mounted.'}
$root=$stores[0].GetRootFolder()
$matches=@()
for($i=1;$i -le [int]$root.Folders.Count;$i++){
    $f=$root.Folders.Item($i)
    if([string]$f.Name -ceq ('OPA265-BW4k7l-'+$id)){$matches+=,$f}
}
if($matches.Count -ne 1 -or [int]$matches[0].Items.Count -ne 0){
    throw 'Expected new empty fixture archive folder.'
}
$folderId=[string]$matches[0].EntryID
~~~
