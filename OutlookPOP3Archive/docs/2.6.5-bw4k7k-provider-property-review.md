## Independent destination-only MAPI properties

The controller first reruns full original BW4k7j/BW4k7i content/recipient/attachment/restart/baseline audit, with fixed exact Claim and baseline hashes. It then obtains original exact destination PST by unique path + profile Outlook + folder and EntryID. It reads the three different properties twice:

| Tag | Property | Requirement |
|---|---|---|
| 0x0E070003 | PR_MESSAGE_FLAGS | Required exact destination value 17, historical original 65555 |
| 0x0E170003 | PR_MESSAGE_STATUS | Optional; absence distinguished from integer zero; cannot compare to source because not captured before Move |
| 0x0E1B000B | PR_HASATTACH | Required true, exactly one attachment, UnRead false |

No value in PR_MESSAGE_STATUS or the unrelated STORE_HTML_OK mask establishes the meaning of the unknown 0x00010000 in PR_MESSAGE_FLAGS. Unknown behavior is **not** waived. The stage rejects unexpected MAPI getter errors, changed Outlook process, inconsistent reads, missing mandatory properties, wrong PST, wrong folder or message identity.
