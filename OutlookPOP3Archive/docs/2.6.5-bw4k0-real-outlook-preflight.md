witness JSON in %LOCALAPPDATA%\OutlookPOP3Archive-BW4j-Suites.

The synthetic BW4j6 matrix remains GitHub-Actions-only. Its modeled +38-byte
size delta is NOT an allowed real MAPI size delta for other messages.

## Operator commands: Windows PowerShell 5.1 STA / Outlook profile

1. Extract the verified BW4k0 DEV ZIP and run:

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

2. Create an entirely new five-TestId plan. Keep SuiteId, PlanSha256,
   and the five exact Subject/Marker pairs.

    powershell.exe -NoLogo -NoProfile -STA -File .\Core\Diagnostics\Invoke-OPA265BW4jSuiteReadOnly.ps1 -Mode NewPlan

3. Manually prepare five disposable received emails in the POP3 Inbox:
   PlainSmall, UnicodePlain (Cyrillic), HtmlBody (actual HTML), Attachment1K
   (one by-value attachment >=1024 bytes), Attachment256K (one by-value
   attachment >=262144 bytes). Each needs the exact planned Subject and Body
   marker. Never use customer correspondence; no automatic email sending.

4. Open Outlook with the Outlook profile, select exactly one matching message
   in the correct POP3 Inbox, and set its new TestId:

    $scriptPath = Join-Path (Get-Location).Path 'Core\Diagnostics\Invoke-OPA265BW4k0SelectedPreflight.ps1'
    $source = 'C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst'
    $suite = '<SuiteId from NewPlan>'
    $planSha = '<lowercase PlanSha256>'
    $testId = '<new selected-case TestId>'

5. Read-only review of the selected message:

    powershell.exe -NoLogo -NoProfile -STA -File $scriptPath -Mode ReviewSelected -SuiteId $suite -TestId $testId -ExpectedPlanSha256 $planSha -SourcePst $source -ExpectedProfileName 'Outlook'

   Expect ExactSelectedDisposableSourceReviewedNoMove.

6. ONLY after reviewing the output, capture the first original immutable
   witness for that TestId:

    powershell.exe -NoLogo -NoProfile -STA -File $scriptPath -Mode CaptureSelected -SuiteId $suite -TestId $testId -ExpectedPlanSha256 $planSha -SourcePst $source -ExpectedProfileName 'Outlook' -ConfirmSourceCaptureOnce

   Expect OriginalSourceWitnessCapturedNoMove and EvidenceSha256.
   Preserve the plan and witness with their SHA256 values. Repeat once
   per new TestId for the remaining four selected messages.

Stop on any validation failure. Do not overwrite an existing witness.
ReviewSelected forbids the capture confirmation switch.
