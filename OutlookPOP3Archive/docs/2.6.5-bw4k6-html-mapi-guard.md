## Read-only BW4k6 audit

`Core/Diagnostics/Invoke-OPA265BW4k6HtmlReadOnly.ps1` supports two modes:

- `PreMoveReview`: validates original immutable BW4j source, BW4k5 source MAPI JSON and both older Claim SHA256s, invokes original BW4k1 **Review only** to verify exact fresh empty isolated PST/folder, twice rereads 15 source MAPI digests and requires complete equality with captured original. Returns destination FolderEntryId only, `OutlookMoveExecuted=False`.
- `PostMoveCompare`: available only after a **separately authorized** one-shot BW4k1 real Move has occurred. Requires operator-supplied SHA of original immutable Claim and exactly pinned destination EntryIDs. Twice uses independent BW4j destination readback to verify source 0 / target 1 and content/HTML/attachments, takes two bounded MAPI snapshots of target, compares digests to original 15 properties, repeats source and Claim integrity checks. Never automatically accepts any MAPI size delta.

Any mismatch **STOP**, never retry `MailItem.Move`. No writer or Move method is present in BW4k6. The original BW4k1 Move is not automatically invoked.
