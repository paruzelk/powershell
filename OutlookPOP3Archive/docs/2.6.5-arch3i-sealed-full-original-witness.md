    SourceEntryId = '00000000E1878292411BC64291BD506DCEFD2A35E4FC3B00'

    ExpectedStoreIdSha256 = 'c6f1cb064a78b6d8c676ace07d6ae8202f2477046e48d17baeade82581837ca3'
    ExpectedSourcePstLengthBytes = [long]7694763008
    ExpectedExistingArchiveLengthBytes = [long]271360
    ExpectedAttachmentCount = 0
    ExpectedArchiveDate = [datetime]'2020-02-13T12:57:58'
    ExpectedOriginalWitnessSha256 = '8782b410253f54cc5374661077cdfc9279bcfba12805f0dab42b461320cb999c'

.\Invoke-ARCH3i.ps1 -Mode Plan @pin | Format-List
.\Invoke-ARCH3i.ps1 -Mode Seal @pin -ConfirmEvidenceWrite -WhatIf | Format-List

$sealed | Format-List
$review = .\Invoke-ARCH3i.ps1 -Mode Review -RunId $run -SealSha256 $sealed.SealSha256
$review | Format-List
~~~

## Все параметры Invoke-ARCH3i.ps1

| Параметр | Тип и значение | Требование |
| --- | --- | --- |
| -Mode | Plan / Seal / Review | По умолчанию Plan |
| -RunId | Канонический lowercase GUID | Обязателен всегда; для Seal новый |
| -SourcePst | Путь к info@stios.ru.pst | Для Plan/Seal |
| -SourceEntryId | Точный hex EntryID | Для Plan/Seal |
| -ArchiveYear | 1900–2100 | На этом этапе 2020 |
| -ExpectedSourceFolderEntryId | Точный hex идентификатор Inbox | Для Plan/Seal |
| -ExpectedStoreIdSha256 | SHA256 StoreID, 64 lowercase hex | Для Plan/Seal |
| -ExpectedSourcePstLengthBytes | int64 > 0 | Для Plan/Seal |
| -ExpectedExistingArchiveLengthBytes | int64 > 0 | Для Plan/Seal |
| -ExpectedAttachmentCount | int 0–256 | Для Plan/Seal; текущий пилот 0 |
| -ExpectedArchiveDate | DateTime, локальное без UTC-конвертации | Для Plan/Seal |
| -ExpectedOriginalWitnessSha256 | SHA256, 64 lowercase hex | Для Plan/Seal; независимо полученный в ARCH3h |
| -ConfirmEvidenceWrite | switch | Обязателен для Seal, разрешает только evidence JSON |
| -SealSha256 | SHA256, 64 lowercase hex | Обязателен для Review |
| -WhatIf | switch | Симуляция без записи/COM |
| -Confirm | switch | Общий ShouldProcess; использовать -Confirm:$false с отдельным явным -ConfirmEvidenceWrite |

## Контракт

Путь evidence: %LOCALAPPDATA%\OPA265-ARCH3i-{RunId}\original-full-semantic-witness.json.
Для каждого RunId одно создание приватной папки с защищённой DACL текущий пользователь + SYSTEM; проверка оригинальной функции ARCH2c2 private ACL. Однократная запись через оригинальную ARCH3c Write-OPA265ARCH3cJsonOnce, CreateNew + Flush(true), без перезаписи, затем независимый Read-OPA265ARCH3cPinnedJson с SHA256 и оригинальными Test-OPA265ARCH2bWitnessSchema / Get-OPA265ARCH3dOriginalWitnessHash. Полная структура хешей оригинального письма сохраняется (без Body/HTML в открытом виде).

Если после создания каталога произошла авария, прежний RunId не повторять; неполные файлы только для ручной диагностики. Review проверяет по внешнему SealSha256, без Outlook. Приватный файл содержит конфиденциальные метаданные, не публиковать в GitHub. SHA не является цифровой подписью.

Вложения оригинальный ARCH2b временно сохраняет в приватном TEMP для хеширования, затем удаляет в штатном режиме. При аварии остатки должны проверяться вручную, не удаляться автоматически.

**ARCH3i не создаёт PST, не вызывает Move, не пишет OperationJournal Intent/Index и не активирует Archive/Resume/Auto.** FullWitnessPersisted=True означает ТОЛЬКО наличие полного оригинального witness в защищённом JSON. Следующий отдельный шаг — реальный original MailMover writer с новым назначением, durable Intent до создания PST, неизменяемый MoveClaimed, независимая проверка после настоящего рестарта Outlook, затем Reconciled и DuplicateIndex. Существующий Archive-2020.pst и его индекс не изменять до решения архитектурного вопроса об общей базе дубликатов.
