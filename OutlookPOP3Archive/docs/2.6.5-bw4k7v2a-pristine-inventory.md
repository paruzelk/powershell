# BW4k7v2a — pre-creation visible PST inventory gate (read-only)

## Scope

BW4k7v2 confirmed that the Outlook test profile has zero accounts, one exact default PST, a dedicated profile name, and a PST not larger than 16 MiB. File size alone does not prove that a test PST contains no previous messages. The failed old BW4k7v pilot was routed to the working profile Drafts, so another attempt must be especially guarded.

BW4k7v2a performs a bounded, read-only inventory **before** creating any pilot folder, template or MailItem. It walks the only isolated PST root and all Outlook-visible subfolders, including Drafts and Inbox. Every folder must have Items.Count = 0. The maximum is 128 folders, depth 32. Any missing/duplicate folder EntryID, incomplete child enumeration, unexpected preexisting item, traversal error, or limit overrun means STOP without a write. The evidence is held only in memory and exposes counts rather than customer subjects, bodies or recipient addresses.

A successful visible-folder inventory is **not** proof of physical PST byte-level emptiness, hidden associated content, recipient preservation or genuine year metadata. No Move/Send/Delete, no retry and no production Worker dispatch have been introduced. Existing original failed SuiteId 78a3e477-98fc-4134-b400-429b3e3b216b, its accidental Draft, earlier evidence and irreversible BW4k7m Claim remain quarantined and unchanged.

## Operator procedure

Use a NEW canonical SuiteId and exactly the dedicated account-free Outlook profile OPA265-BW4k7v2. From an extracted, independently verified project-only DEV ZIP use Windows PowerShell 5.1 STA:

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

Follow [the original BW4k7v2 operator guide](2.6.5-bw4k7v2-isolated-profile-pilot.md) for Plan, Prepare, manual fresh PST/default-profile setup, Inspect, CreatePilot and VerifyPilot. CreatePilot now checks all visible PST folders just before the first PST operation. A gate failure is final for the SuiteId: preserve all evidence, send the exact stage/HRESULT and DO NOT attempt CreatePilot again for that GUID.

The new optional success fields are PristineVisiblePstBeforeCreateVerified=True, ObservedVisibleFolderCountBeforeCreate and PhysicalPstByteEmptinessProven=False. This does not grant any new production permission.
