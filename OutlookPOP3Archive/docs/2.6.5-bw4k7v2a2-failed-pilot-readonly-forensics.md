## New diagnosis

`Core/Diagnostics/Invoke-OPA265BW4k7v2a2FailedPilotReadOnlyReview.ps1` has Plan and Review modes. It uses the **same failed BW4k7v2a1 SuiteId** for independent observation. It verifies the original intent, current Outlook profile and POP3 delivery store, locates the existing test PST by exact path, finds only its named synthetic test folder and reads up to 16 items **only in that test folder**. For any matching subject it compares current EntryID, Class, Parent.StoreID, Parent.EntryID and a fresh `GetItemFromID(itemEntryId, targetStoreId)` read.

It never creates/attaches/removes PST, never mutates source or test messages, never saves, moves, sends or deletes any item, never reads any *other* store's mail content and never modifies evidence. The report is in memory and is not saved to disk. Missing/unattached PST is reported instead of automatically mounted.

If a pilot exists in the correct folder now, it establishes **current observed identity** only; it cannot retrospectively prove the exact original failed assertion or guarantee provider state was stable during the previous `CreatePilot` run.
