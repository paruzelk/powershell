2. Outlook profile "Outlook" is already running.
3. Prepare a NEW disposable synthetic email (different TestId), and
   verify its exact BW4f marker/Subject, no attachments, and POP3 PST.
4. Obtain exact fresh source FolderEntryId, EntryId, InternetMessageId,
   SearchKeySha256 and ContentFingerprintSha256 by existing BW4c
   targeted read-only review. Never reuse the old moved fixture pins.

Set variables from actual newly observed values:

    if($LASTEXITCODE -ne 0){throw 'BW4h2 SourceReview failed.'}

Only when SourceReview passed, create exact immutable witness ONCE:

    if($LASTEXITCODE -ne 0){throw 'BW4h2 Capture failed; do not retry a failed/partial CreateNew.'}

Preserve EvidencePath + EvidenceSha256 in a separate review note.
SourceCapture creates only one per-user JSON. IT NEVER MOVES MAIL.
After a future separately approved NEW fixture BW4g one-shot Move
(and only after its permanent BW4g claim is present), execute:

    $afterArgs=@($args)
    $afterArgs+=@(
      '-DestinationPst','<actual precreated GUID disposable PST path>',
      '-DestinationFolderEntryId','<exact new destination folder EntryID>',
      '-DestinationEntryId','<actual new moved EntryID>',
      '-ExpectedSourceEvidenceSha256','<independently pinned SHA256 of BW4h2 source witness>'
    )
    & powershell.exe @afterArgs -Mode DestinationCompare

DestinationCompare:
- requires original immutable SHA256 and an existing BW4g one-shot
  claim. Refuses to manufacture source evidence after a claim.
- re-runs BW4h full post-Move independent source-zero/target-one
  identity and historical journal + claim check.
- independently re-reads exact moved destination item and compares
  each of five fields separately against prior source evidence.
- recognizes only MAPI Size changed vs content/subject/sender/time
  changed; always fails closed for identity mismatches.

Example statuses:
  AllFiveFieldsMatchReadOnly
  OnlyMAPIMessageSizeChangedManualReview
  ContentFieldDriftNeedsManualReview
  BlockedIdentityDrift

These statuses are diagnostic and NEVER authorize a retry, journal
modification or production Worker activation. Physical PST byte
durability and full MAPI binary message equality remain UNPROVEN.
