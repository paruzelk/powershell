## Mandatory profile isolation

BW4k7v2 does NOT permit the user's original working profile Outlook. Instead require dedicated profile named OPA265-BW4k7v2 with ZERO mail accounts, exactly ONE attached PST, that sole PST set as Outlook DEFAULT data file, and its FilePath exactly matching a newly prepared LOCALAPPDATA test path. The script verifies all four conditions before any mail save, and never adds/mounts a PST or switches profiles. The original POP3, IMAP and old disposable stores must not be present.

An account-free profile in Outlook 2019 might not be possible on every installation. Microsoft's /PIM advice specifically states applicability to Outlook 2016 and Microsoft 365; do not assume it is available for 2019. If this fails, STOP and use a dedicated test VM/new Windows environment with no real mail accounts instead. Do not weaken any account/store/profile safety gate.

This stage creates only ONE pilot message via a template (.oft) and explicit InFolder destination. It checks actual post-Save Parent.EntryID, Parent.StoreID, target folder item count and one independent by-ID double-read before sealing the original pre-Move manifest using FileMode.CreateNew and Flush(true). Failure stops permanently for that SuiteId, no repair or automatic retries. Exact COM failure stage and HRESULT reported. No bulk eight-mail creation or real Move/Send/Delete.

## Modes

Plan: generate a new canonical SuiteId with new isolated directory/PST/template/manifest paths; no Outlook, no file writes.
Prepare: create that empty directory once; no PST or mail changes. Must not be rerun for an existing suite.
Inspect: require running separate account-free profile, exactly one DEFAULT PST with expected file path. No write.
CreatePilot: explicit per-GUID approval, only on fresh profile/PST (max 16 MiB), no existing pilot root/template/manifest. Create one template via Application.CreateItem(0).SaveAs(templatePath,2), one MailItem via CreateItemFromTemplate(templatePath, PilotFolder), Save, then verify actual Parent and original StoreID. Failure STOP, preserve evidence.
VerifyPilot: require same suite and original sealed SHA256, new Outlook process after full restart, exact StoreID, item/folder count and original semantic hash. No new mail or manifest.

Synthetic year is a label only. This does not prove real ReceivedTime/SentOn, genuine Sent, raw attachment preservation, durable crash resume, physical archive capacity, SEM-001 unknown flag safety, or production readiness. No production Archive/Resume/Auto is enabled.

## Operator guide — Windows PowerShell 5.1 STA

Download and extract verified project-only BW4k7v2 DEV ZIP into a NEW folder, then run:

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

Plan without Outlook:

    $v2 = & '.\Core\Diagnostics\Invoke-OPA265BW4k7v2IsolatedPilotPreflight.ps1' -Mode Plan
    $v2 | Format-List

Create the empty suite directory once:

    $suite2 = [string]$v2.SuiteId
    $readyDir = & '.\Core\Diagnostics\Invoke-OPA265BW4k7v2IsolatedPilotPreflight.ps1' -Mode Prepare -SuiteId $suite2 -Confirm:$false
    $readyDir | Format-List

MANUAL OUTLOOK SETUP: Close the old Outlook profile completely. Create a separate account-free Outlook profile EXACTLY named OPA265-BW4k7v2, with only one NEW standalone PST at the exact $v2.RequiredPstPath. Make it the DEFAULT data file in that separate profile. Never add original info@stios.ru PST, any IMAP account, any old PST or any mail account. If this is not possible on Outlook 2019, STOP. Microsoft profile guidance:
https://support.microsoft.com/en-us/outlook/create-an-outlook-profile

Run read-only profile inspection:

    $inspect = & '.\Core\Diagnostics\Invoke-OPA265BW4k7v2IsolatedPilotPreflight.ps1' -Mode Inspect -SuiteId $suite2
    $inspect | Format-List

ONLY if Status is DedicatedProfileExactSingleDefaultPstAndZeroAccountsConfirmed, AccountsCount=0, StoresCount=1, Isolation.Isolated=True:

    $pilot2 = & '.\Core\Diagnostics\Invoke-OPA265BW4k7v2IsolatedPilotPreflight.ps1' -Mode CreatePilot -SuiteId $suite2 -ConfirmIsolatedPilot -ApprovalText ('CREATE BW4K7V2 PILOT '+$suite2) -Confirm:$false
    $pilot2 | Format-List

On success keep original ManifestSha256; completely close OUTLOOK.EXE, restart Outlook with same dedicated profile, then:

    $verified2 = & '.\Core\Diagnostics\Invoke-OPA265BW4k7v2IsolatedPilotPreflight.ps1' -Mode VerifyPilot -SuiteId $suite2 -ExpectedManifestSha256 ([string]$pilot2.ManifestSha256)
    $verified2 | Format-List

Expected successful VerifyPilot:
- Status = OnePilotReopenedAfterOutlookRestartExactFolderAndSemanticsMatched
- PilotMailItemCount=1
- ExactIsolatedFolderAndStoreVerified=True
- OriginalPilotSemanticsReverified=True
- AllEightMailItemsTested=False
- WriterPermit=False and ProductionReady=False.

If ANY error occurs share exact error including stage/HRESULT, do not retry CreatePilot or remove partial data. The old failed PST, accidental Draft and historical Evidence/Claim are out of scope.

No hidden production writer, no user mail, no Outlook profile auto-switch, no PST auto-mount, no rerun of earlier irreversible Move; all new PowerShell files UTF-8 BOM and PS5.1 Pester/PSScriptAnalyzer CI with inherited BW4j6 and BW4k7v1 safety gates, release ZIP containing only OutlookPOP3Archive.
