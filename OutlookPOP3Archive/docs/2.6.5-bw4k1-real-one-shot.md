## Separation of roles

- Seal mode: verifies all five original local witness files and prints a SHA256 digest over ordered TestId=SHA256 lines.
- Review mode: checks the source POP3 Inbox, exact original MailItem identity and field/binary hashes, historical quarantine, unique target PST and empty named target folder. It NEVER calls Move.
- Execute mode: requires an explicit switch, exact operator approval phrase, a pinned Review destination folder identity and the exact five-witness seal. Writes a durable irreversible claim first, then attempts exactly one real MailItem.Move. Any crash, failure or prior claim blocks all retries.
- Execute with WhatIf: tests ShouldProcess without claim or Move.
- Post-Move reconciliation: independent read-only BW4j DestinationReview. Move return is not evidence of durable delivery.

GitHub CI never accesses real Outlook or PSTs. This DEV gate is not approved for production Archive/Resume/Auto (those workers stay disabled).
