## New build-only audit

- Core/Runtime/ReleaseReadiness264.ps1: offline, read-only exact source
  SHA-256 inventory (canonical ordinal relative paths, UTF-8 with LF).
  Checks an externally pinned Git commit and ZIP SHA-256, the exact
  internal ZIP root identical to its filename stem, every ZIP entry's
  uncompressed bytes against the extracted source, uniqueness, missing
  or additional entries, and BUILD-INFO.json metadata.
- Core/Diagnostics/Invoke-OPA264GPackageReview.ps1: standalone opt-in
  offline command requiring -Review and external expected Git commit/
  ZIP SHA-256 values. It reports a JSON-only development readiness
  assessment, never authorizes production.
- Tests/Runtime/ReleaseReadiness264.Tests.ps1: 22 synthetic tests against
  altered source, unexpected ZIP root/contents, incorrect hashes,
  inconsistent metadata, optimistic worker switches, forged CI claim
  and incorrect release authorization.

The package ZIP must include ONE directory:
OutlookPOP3Archive-2.6.4-G-dev-g<source-sha8>/
with all exact source files and an additional BUILD-INFO.json.
No unrelated project files or wrapper repo root are allowed.
BUILD-INFO.json is excluded from the source inventory because it is
a generated, package-specific attestation record.

### Independent validation (Windows PowerShell 5.1)

From the extracted OutlookPOP3Archive project directory:

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

Expected 464 Pester tests / 34 containers, no failures or skips.

Next, obtain ExpectedSourceCommit and ExpectedZipSHA256 from an
EXTERNAL trusted source, not from inside the ZIP itself. Run:

    .\Core\Diagnostics\Invoke-OPA264GPackageReview.ps1 -ZipPath '..\OutlookPOP3Archive-2.6.4-G-dev-g<sha8>.zip' -ExpectedSourceCommit '<full-40-hex-Git-source-commit>' -ExpectedZipSHA256 '<64-hex-checksum>' -Review

The review recomputes source inventory, ZIP checksum and ZIP entry
bytes. It never writes files, reads Outlook/PST data, launches workers
or modifies the operation journal. A trusted external SHA is still
needed to detect malicious re-packaging of an entirely different
source tree; a digest copied from inside the archive is NOT
independent attestation.
