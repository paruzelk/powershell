## Usage — Windows PowerShell 5.1 STA
~~~powershell
$common=@{ProfileName='Outlook';SourcePst='C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst';ConfirmTestArchive=$true}
.\Invoke-OPAArchiveBatches.ps1 @common -ConfirmOutlookRestart -IncludeRootMail -IncludeFolderPath '\\info@stios.ru' -BatchSize 10 -MaxMessages 20 -MaxBatches 2 -OlderThanMonths 60 -ArchiveGrouping YearQuarter -WhatIf
~~~

Remove WhatIf only for bounded live acceptance after CI PASS. Existing size cap defaults and DisableArchivePstSizeLimit unchanged. For one batch use OutlookPOP3Archive.ps1 -Mode Archive @common -IncludeRootMail -IncludeFolderPath '\\info@stios.ru' -Limit 10 -OlderThanMonths 60 with manual restart/Resume.

- IncludeRootMail: explicit Archive-only test opt-in. Without IncludeFolderPath includes root and normal eligible folders; exact root path selects only direct root Items, not children. Without opt-in root remains excluded from writer. Only eligible Class=43 with age and EntryID duplicate checks.
- Destination annual PST: None -> __OPA_ROOT_MAIL__, Year -> year\__OPA_ROOT_MAIL__, YearQuarter -> year\Qn\__OPA_ROOT_MAIL__, YearMonth -> year\MM\__OPA_ROOT_MAIL__. A top-level user folder with the reserved name (case insensitive) is blocked, ordinary nested paths unchanged.
- Root comes from the selected Store.GetRootFolder(). Original source parent/store identity, semantic witness, durable claim, route assertion, independent restart verification, journal and index remain mandatory. Resume and RecoverTransaction never accept IncludeRootMail; pending route and root observation govern verification.
- Inventory stays read-only. RootArchiveEnabled=False describes inventory only; RootArchiveSupported=True denotes explicit writer availability.
- Existing duplicate index uses source EntryID; identical copies with distinct EntryIDs are not automatically discarded. No content deduplication claim.
