## Controller full syntax

| Parameter | Meaning |
|---|---|
| SourcePst (required) | Exact local POP3 delivery test PST; existing, not UNC/reparse |
| ProfileName (required) | Exact Outlook profile |
| ConfirmTestArchive | Required explicit test consent |
| ConfirmOutlookRestart | Required consent to graceful Outlook Quit/reopen during verification; affects entire profile, close open messages first |
| BatchSize | 1..500, default 500. Complex opt-in <=10 |
| MaxMessages | Total verified messages 1..2147483647; default 10000 |
| MaxBatches | 1..100000, default 100 |
| OlderThanMonths | 0..1200, default 12; 0 requires IgnoreAge |
| IgnoreAge | Explicit acknowledgment of no age filter |
| ArchiveGrouping | None/Year/YearQuarter/YearMonth; default YearQuarter. PST filenames still year-based |
| IncludeFolderPath | Exact paths within selected POP3 store, no wildcard. Empty eligible folders allowed |
| ConfirmComplexAttachments | Experimental type 5/6 attachment consent, batch <=10; real type 5 tested once, OLE not certified |
| MaxArchivePstSizeGB | Default 10, 0.01..1000 GiB |
| SafetyMarginGB | Default 0.5, 0..100 GiB; must be smaller than max |
| DisableArchivePstSizeLimit | Disables application rollover size threshold only; mutually exclusive with max/reserve. Provider limits and filesystem constraints remain. No registry modification |
| RestartTimeoutSeconds | 5..300, default 60; timeout only covers process wait after Quit returns (COM itself may block) |
| RecoverTransaction | Exact pending transaction ID, reconciliation-only; cannot supply new archive parameters. No subsequent Archive |
| WhatIf | No Outlook or persistent writes |

Original main Archive/Resume options are retained, including new DisableArchivePstSizeLimit (Archive-only, explicit test). Original per-batch Limit remains 1..500 intentionally. New controller total MaxMessages can exceed 500 without making single transaction unbounded. A batch must reach Verified=Reconciled=Indexed=Returned before another Archive. No forced process termination, no Send, no automatic uncertain Move retry, no stale pending deletion. Normal Outlook startup may initiate configured send/receive; no unsent mail or open inspectors permitted for automatic shutdown. If COM is unavailable, an Outbox cannot be inspected, Outlook is not in the expected profile, or graceful restart fails, stop and use manual restart/Resume. Original per-user mutex held for entire sequence, recursive on same STA thread. Original journals are authoritative; separate ARCH6-run-*.jsonl events show progression. A restarted controller refuses any existing pending unless exact RecoverTransaction is supplied. If crash occurred before a durable receipt, original Resume may fail closed; operator/manual review required.

## ARCH6a
Include empty eligible folders during Resume and exact folder selection; add root ONLY to independent absence verification; preserve system-subtree exclusions. Root inventory lists Outlook Class counts to explain observed 500 root items; root mail archiving intentionally NOT enabled until actual inventory and route policy confirmed.

## ARCH6b/c
Bounded automatic sequence, repeated original restart verification. Reduce controlled per-folder candidate pool to top Limit rather than three times; source absence verification still scans every item but retains only relevant IDs, fails on missing ID/count changes. This is a memory/selection optimization, not measured 90 GB performance. No unsafe negative COM lookup shortcut.

## ARCH6d/e
Stop after any skipped item (including zero-move batch), incomplete selection, unknown receipt, restart failure or index mismatch. No persistent automatic skip/quarantine across new operator runs: review skipped entries before starting a new sequence. Disable application cap only on explicit switch; finite capacity unchanged. Existing controller limit is total verified messages, not byte size or PST physical shrinkage. User should not disable provider size protection. Run journal is diagnostic, not replay authority.
