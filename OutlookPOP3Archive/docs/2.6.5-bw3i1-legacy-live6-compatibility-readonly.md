# 2.6.5 BW3i1 — historical BW3a vs legacy LIVE6 compatibility audit (READ ONLY)

## Why BW3i stopped in actual Outlook

The operator's local BW3i full CI completed **1212 Pester/57 containers PASS**.
The actual diagnostic stopped at strict legacy LIVE6 -Review comparison:
"BW3i LIVE6 review does not match one outstanding exact synthetic Intent."

Source review uncovered incompatible evidence protocols:
- Historical **BW3a** is a normal, previously authorized, exactly
  one-shot Worker Move with BW3 dispatch/attempt/result claims.
- Legacy LIVE6 uses LIVE5 -> LIVE4 classification of a *controlled
  crash*, requiring its own controller-dispatch.claim, crash-barrier.json
  and controller-result.json evidence files.
- BW3h already independently confirmed this historical BW3a source=0,
  archive=1, exact destination EntryID, both Worker claims, unchanged
  original Intent, and independently saved one-run human size approval.
- BW3i incorrectly required LIVE6 to report a positive MoveConfirmed
  when legacy LIVE4 crash-specific evidence was not part of this
  historical BW3a operation.

BW3i1 tests a **specific and safe hypothesis**, it does not assume the
unobserved legacy review output. It requires a precise old LIVE6
-Review / InspectionFailed result, no invented size information,
no LIVE4 crash files, original seven unchanged hashes, exact BW3h
proof and one intact Intent. Any different legacy response FAILS CLOSED.

A matching BW3i1 result confirms inapplicability of the OLD
LIVE6 executor, NOT journal-readiness or permission to write.

2. Validate exact RunId, SourcePst, original journal SHA256.
3. Require ALL THREE legacy LIVE4 controlled-crash artifacts ABSENT.
   Unexpected partial or full legacy artifacts are STOP conditions.
4. Require live6-resolution.claim absent.
5. Hash seven immutable files; validate intact single original Intent.
6. Rerun BW3h and all its independent read-only Outlook checks.
7. Rerun legacy LIVE6 with -Review ONLY (NEVER -Execute).

   source/archival size fields 0 (not measured by legacy),

   CanExecute=False and CanExecuteWithExplicitSizeConsent=False,
