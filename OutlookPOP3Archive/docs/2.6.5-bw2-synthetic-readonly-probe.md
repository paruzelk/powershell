# 2.6.5-BW2 — isolated read-only synthetic Outlook probe (DEV)

## Scope / safety

BW1 successfully passed real Windows Archive + Resume single-Ping canaries.
BW2 adds a NEW explicit canary operation ProbeSyntheticPstReadOnly, executed
inside a separate native Windows PowerShell 5.1 STA Worker. It attaches ONLY
to already-running Outlook and reads exactly two LIVE3 synthetic test folders.
It does NOT run Archive/Resume, MailItem.Move, PST creation/mount/removal,
profile switching, backups, journal append, claim deletion, or any retry.
The main CLI exits BEFORE New-OPAComSession and MailMover.

BW2 supports both previously audited fixtures:
- RunId 77854a93-ecfd-42c7-b58e-2948fe9afa88: one unresolved Intent, source=1/archive=0; NoMoveObserved.
- RunId c7e87652-e501-43ff-b622-5dcd87aee438: Intent + LIVE6 Reconciled and live6-resolution.claim, source=0/archive=1; MoveConfirmed. ArchiveEntryId must match claim.

An unresolved Intent which *physically moved* is deliberately refused: it needs
independent LIVE5 classification, not optimistic BW2 success.
An interrupted or unclaimed LIVE6 resolution is refused.
The original test RunIds are **never** reused for Move.

## Hard gates
- Explicit -Mode Archive or Resume, -ProfileName Outlook, -Limit 1, -WhatIf.
- Explicit -WorkerPilot -ConfirmDevWorkerPilot -WorkerPilotProbeSynthetic.
- Both -WorkerPilotRunId (existing LIVE3 fixture GUID) and -WorkerPilotSourcePst (exact local existing approved POP3 source PST).
- Exactly one child operation, default 10-second timeout (1..30 allowed).
- Resume also needs an arbitrary nonzero -Transaction GUID; it is validated but NOT executed.
- Child revalidates source/Archive PST paths, scope marker, request, POP3 DeliveryStore, StoreIDs, folder EntryIDs and paths; exact GUID-scoped synthetic InternetMessageId + subject; journal and claim, pre/post SHA-256; source/archive counts and resolved ArchiveEntryId. No other folders.
- Parent rechecks the child's process PID, RequestId, STA, journal SHA, RunId, OperationId, counts, state and exact claim EntryID.
- Any refusal stops; NO fallback to FIX13b mutation or automatic retry.
- Normal BW1 -WorkerPilot without -WorkerPilotProbeSynthetic remains one Ping.
- Default (pilot disabled) FIX13b path unchanged. RELEASE.json production Worker flags remain false.

## BW2 real Windows synthetic read-only test

Open the already approved Outlook profile "Outlook" as the same user (do not start,
kill or reconfigure Outlook from the script). Extract the DEV build; use Windows
PowerShell 5.1, run from its project directory. Previously approved source PST:

    $source='C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst'

First the original PRE-MOVE fixture, read-only only:

    .\OutlookPOP3Archive.ps1 -Mode Archive -ProfileName Outlook -Limit 1 -WhatIf -WorkerPilot -ConfirmDevWorkerPilot -WorkerPilotProbeSynthetic -WorkerPilotRunId '77854a93-ecfd-42c7-b58e-2948fe9afa88' -WorkerPilotSourcePst $source | Format-List

Expected Status=SyntheticReadOnlyProbePassed, State=UnresolvedIntent,
Decision=NoMoveObserved, SourceItemCount=1, ArchiveItemCount=0,
OnlySyntheticFoldersInspected=True, OutlookMoveExecuted=False,
JournalChanged=False, ProductionReady=False.

Second the completed LIVE6a POST-MOVE fixture:

    .\OutlookPOP3Archive.ps1 -Mode Archive -ProfileName Outlook -Limit 1 -WhatIf -WorkerPilot -ConfirmDevWorkerPilot -WorkerPilotProbeSynthetic -WorkerPilotRunId 'c7e87652-e501-43ff-b622-5dcd87aee438' -WorkerPilotSourcePst $source | Format-List

Expected State=Reconciled, Decision=MoveConfirmed, SourceItemCount=0,
ArchiveItemCount=1, ArchiveEntryId the previously pinned LIVE6a value,
JournalSha256=072d7fa74b73cb16e474918f51222fa2fe7f280dee5375047d502448a11d310b,
OutlookMoveExecuted=False, JournalChanged=False, AutomaticRetryAllowed=False.

Resume entry routing can be verified using a NEW RANDOM transaction GUID;
that GUID is NOT read from the transaction store and does not perform Resume:

    $tx=[guid]::NewGuid().ToString('D')
    .\OutlookPOP3Archive.ps1 -Mode Resume -ProfileName Outlook -Transaction $tx -Limit 1 -WhatIf -WorkerPilot -ConfirmDevWorkerPilot -WorkerPilotProbeSynthetic -WorkerPilotRunId 'c7e87652-e501-43ff-b622-5dcd87aee438' -WorkerPilotSourcePst $source | Format-List

## Stop rules
If an error occurs, preserve the run files. Do not mount PST,
retry a Move, delete claim, change the journal, or execute LIVE6a -Execute.
This is a DEV read-only probe only. It does NOT prove that production mail
routing through Worker is safe. RealMailMoveViaWorker=False and
ProductionReady=False, independent of probe result. FIX13b remains production.
