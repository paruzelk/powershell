## Synthetic fixtures

The BW4k7u worker Core/Worker/BW4k7uSyntheticBatch265.ps1 creates exactly 12 deterministic fabricated items in process memory, uniquely identified by a new suite GUID and SHA256 fixture manifest:

8 eligible simulated MailItem cases:
- Inbox2020Plain, Inbox2021Unicode (Cyrillic), Inbox2024Html, Inbox2025Attachment1K (exact 1024 synthetic bytes).
- Sent2023Unicode with synthetic Bcc, Sent2025Attachment256K (262144 synthetic bytes).
- User2022Nested under \Projects\Alpha\2022, User2024HtmlAttach under \Projects\Beta.

4 excluded and preserved cases:
- Inbox2026Retained: current-year message excluded by ArchiveBeforeYear=2026.
- InboxNdrRetained, InboxReadReceiptRetained and InboxMeetingRetained: non-MailItem class patterns, never auto-archived, discarded or moved.

Each case has synthetic Class, MessageClass, source folder and year, sender and ordered To/Cc/Bcc, text/HTML, dates, read/followup/categories, model MAPI flags, logical modeled size, and any attachment payload. SHA256 is computed on actual decoded synthetic attachment bytes. No customer mail or real PST attachments are read. The suite manifest guards the exact twelve original fixtures.

## Simulated yearly PST capacity and folder structure

Get-OPA265BW4k7uSyntheticCapacityPlan reuses BW4k7r default 45,000,000,000-byte maximum archive PST forecast with 3,000,000,000-byte safety margin, estimated 25% growth and 65536 bytes overhead per mail. Every eligible synthetic MailItem is assigned one forecast Archive-YYYY.pst and the original folder hierarchy path, with estimated rollover to Archive-YYYY-02.pst if the forecast segment fills. SimulatedSegmentCapBytes=420000 deliberately triggers a synthetic Archive-2025-02.pst demonstration. It is only artificial in-memory capacity. This script does not read or edit Outlook PST size registry settings or create any PST.

## Model-only per-item Intent/Claim and fault tests

The in-memory ledger holds one modeled row for each of eight eligible synthetic messages:
UnclaimedSourceOnly -> ModeledIntentNoDiskClaim -> ClaimedSourcePresentNeverRetryAutomatically -> DestinationOnlyAwaitIndependentReconciliation -> SyntheticReconciledRiskReviewOnly.

Set-OPA265BW4k7uSyntheticPhase does not call Outlook MailItem.Move, file IO, journal fsync or any PST API. ModelMove deep-clones a synthetic case in memory and toggles synthetic presence flags; independent read-only reconciliation checks content, recipients, sender, folders, times, flags, and exact attachment raw SHA256, then uses prospective BW4k7t semantic acceptance categories A/B/C. Unknown 0x00010000 remains Category C review only; no automatic waiver or residual-risk approval.

Invoke-OPA265BW4k7uSyntheticBatch supports injected AfterIntent, AfterClaim and AfterMove failures on a chosen fabricated case. It stops with no automatic retry/resume. A claimed message whose source is still modeled present requires manual reconciliation; a destination-only message may be compared, never moved a second time. Duplicate Intent/Claim/Move or second batch invocation is rejected.

**IMPORTANT: The in-memory ledger and its review DO NOT survive PowerShell process exit.** There is NO durable on-disk Intent/Claim/journal, no actual power-loss simulation, no Outlook restart verification, no physical PST durability proof and no production permission. Results from BW4k7u must NEVER be presented as real crash/restart recovery. All old test PSTs, old messages, Evidence and Claims remain unchanged.

## Operator runbook (Windows PowerShell 5.1, no Outlook required)

Download the versioned project-only DEV ZIP and verify its published SHA256. Extract the project folder and execute from inside it:

CI verification:
    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

Plan, no synthetic moves:
    $pre = & '.\Core\Diagnostics\Invoke-OPA265BW4k7uSyntheticMultiItemPreflight.ps1' -PlanOnly

    $pre.AllocationTable | Format-Table Name, Role, Year, OriginalFolderPath, ArchivePstFileName, SegmentNumber -AutoSize
    $pre.PreservedObjects | Format-Table Name, Kind, Year, Reason -AutoSize

Full eight-item synthetic in-memory batch:
    $batch = & '.\Core\Diagnostics\Invoke-OPA265BW4k7uSyntheticMultiItemPreflight.ps1'
    $batch | Format-List Status, EligibleSyntheticMailCount, PreservedCurrentYearAndNonMailCount, OutlookMoveExecuted, DiskIntentClaimOrJournalWritten, CrashDurabilityOrRealResumeProven, WriterPermit, ProductionReady
    $batch.RecoveryReview | Format-List

    $cap = & '.\Core\Diagnostics\Invoke-OPA265BW4k7uSyntheticMultiItemPreflight.ps1' -PlanOnly -SimulatedSegmentCapBytes 420000
