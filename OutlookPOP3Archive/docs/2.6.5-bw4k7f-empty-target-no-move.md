2. Runs **two** independent full BW4k7e `Verify` operations, which rerun all prior semantic/correspondence checks, SHA256 of original attachment bytes and 3 prior Move claims.
3. Requires source POP3 Inbox and exact original EntryID, with one unique matching `InternetMessageId` whose searched EntryID equals the original.

5. Requires exactly one existing, top-level target folder `OPA265-BW4j-87e72fd09e774098a403cbe99870b9e7`, inside that target store, with **zero** messages. Source must have one matching message and target zero; duplicate folder, nonempty folder, invalid parent/store/EntryId, missing PST, or any current Claim fails closed.
6. Repeats source snapshot verification and target empty/source unique checks without allowing changes. `-WhatIf` performs the same review but returns `WhatIfNoClaimNoMove`; no Claim is created.
7. `WriterPermit=False`, `OutlookMoveExecuted=False`, `AutomaticRetryAllowed=False`, `ProductionReady=False`. This cannot be used as an archival executor.
