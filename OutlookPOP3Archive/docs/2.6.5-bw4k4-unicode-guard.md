## Workflow

1. In Outlook 2019 profile `Outlook`, create ONE new Unicode PST of name
   `OPA265-BW4j-74912f94d52348569efdd5528a92426f-32cf83511f58408da5e7befd1c6c43e0.pst`
   next to the POP3 source PST. Create ONE empty first-level mail folder
   `OPA265-BW4j-32cf83511f58408da5e7befd1c6c43e0`.
2. Run `Core/Diagnostics/Invoke-OPA265BW4k4UnicodeReadOnly.ps1 -Mode PreMoveReview`
   with all exact original pins, source PST, destination PST and source EntryID.
   This independently calls BW4k1 real `Review` without any Move and
   reads current MAPI 15-property snapshot twice, demanding equality
   with the original immutable source capture.
3. **Stop on any mismatch.** A PASS returns an exact DestinationFolderEntryId.
   PreMoveReview is NOT a Move permit; a separately approved BW4k1a
   `Execute -WhatIf` must precede any irreversible Move.
4. Only after a separately executed one-shot BW4k1 and independently pinned
   Claim SHA256 and returned destination item/folder EntryIDs may BW4k4
   `-Mode PostMoveCompare` be run.
5. PostMoveCompare verifies the original MAPI SHA, source witness and
   five original witness hashes, the exact immutable one-shot Claim,
   two independent BW4j source-zero/destination-one reviews and two
   exact-target MAPI 15-property snapshots; it reports which values
   changed or became unavailable without permitting any size drift.
