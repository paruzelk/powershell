## BW4k7a-only read-only operation

`Core/Diagnostics/Invoke-OPA265BW4k7aAttachmentSizeDriftReview.ps1`:
- Runs only in Windows PowerShell 5.1 STA / Outlook profile `Outlook`.
- Validates immutable original plan, five original source witnesses, original historic seven hash quarantine and original three irreversible Move Claims.
- Validates exact POP3 PST, original Inbox, exact source EntryId, original InternetMessageId unique in Inbox.
- Captures two **read-only** full current witnesses, each including a temporary copy and SHA256 of the same synthetic by-value attachment; requires the two live witnesses be identical.
- Compares original vs live original witness **ALL fields except `Size`**, including `Attachments[0].FileName/ByteCount/Sha256`.
- Reports old `Size`, current `Size`, delta, any changed non-size field names (never mutates originals), live `PR_MESSAGE_SIZE` and `PR_MESSAGE_FLAGS` from double stable 15 MAPI reads.
- Returns `OnlySourceMailItemSizeDriftUnapproved` only if every other field and the original attachment SHA match, or `STOP_OtherWitnessFieldDrift` if there are more differences.
- **No Move, no Capture, no original witness rewrite, no historical journal mutation, no +38-byte consent, no automatic retry, no production.** Never delete evidence or regenerate fixture. Any diagnostic STOP is a final reason for manual analysis, not an invitation to bypass.
