## BW4k5 bounded read-only workflow

`Core/Diagnostics/Invoke-OPA265BW4k5HtmlPreMoveMapi.ps1` only supports
`-Mode Review` and `-Mode Capture -ConfirmCaptureOnce`.

It requires Windows PowerShell 5.1 STA, already-running Outlook profile
`Outlook`, the original POP3 source PST, original 5-case plan SHA256,
original 5-source-evidence seal and two unchanged original irreversible
`PlainSmall`/`UnicodePlain` attempt claims. The original Unicode metadata
evidence SHA256 must also remain unchanged.

The source `HtmlBody` evidence SHA256 and exact SourceEntryId are computed
from the locally stored *immutable original* BW4j witness, not guessed.
They are transitively authenticated by the independently pinned full five
witness SHA256 seal. Both values are returned by Review for recording.

BW4k5 performs:
1. Historical seven-file Intent/claims isolation and immutable old seals.
2. Exact source Inbox, StoreId, InternetMessageId one-match, operator
   fixture TestId, subject, Body, nonempty HTMLBody and zero attachments.
3. Two identical independently captured original source witnesses.
4. Two successive bounded 15-tag MAPI read-only snapshots; SHA256 of
   sensitive content (no raw headers, HTML, body or attachments).
5. Repeat immutable SHA and Claim checks after reads.
6. `Review`: no file writes. `Capture`: one CreateNew/Flush(true)
   UTF-8 BOM JSON under
   `%LOCALAPPDATA%\OutlookPOP3Archive-BW4k5-SourceSnapshots\suite-<SuiteId>\fixture-<TestId>.json`.
   A second Capture always blocks; never overwrite or delete this record.
