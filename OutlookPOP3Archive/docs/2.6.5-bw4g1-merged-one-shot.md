Under the SAME Windows user with Outlook profile "Outlook" open, run

    $ErrorActionPreference='Stop'

    $source='C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst'
    $outlook=[Runtime.InteropServices.Marshal]::GetActiveObject('Outlook.Application')

    $matches=0

            [IO.Path]::GetFullPath($path),[IO.Path]::GetFullPath($destPst),
            [StringComparison]::OrdinalIgnoreCase)){$matches++;$destStore=$store}
    }
    if($matches -ne 1){throw 'New test PST not uniquely mounted.'}

## Standalone isolated one-shot worker: REVIEW first (no claim/no Move)

In the same PowerShell session create a list of arguments for the
separate native Windows PowerShell 5.1 STA process. Use single-quoted
strings for literal InternetMessageId; an argument list preserves '$'.

    $scriptFile=Join-Path (Get-Location).Path 'Core\Diagnostics\Invoke-OPA265BW4gOneShotDisposableMove.ps1'
    $workerArgs=@(
      '-NoLogo','-NoProfile','-STA','-File',$scriptFile,
      '-RunId','a7b51427-7494-43f4-bc96-64915f6bee7e',
      '-SourcePst',$source,
      '-ExpectedJournalSha256','5a68dbc4186c69eff13e49c7d69a19f16eba86e04969bb5aea3be0327820a648',
      '-FolderEntryId',([string]$mail.Parent.EntryID),
      '-CandidateEntryId',([string]$mail.EntryID),
      '-ExpectedProfileName','Outlook',
      '-CandidateReviewId',([guid]::NewGuid().ToString('D')),
      '-ExpectedInternetMessageId',([string]$pin.InternetMessageId),
      '-ExpectedSearchKeySha256',([string]$pin.SearchKeySha256),
      '-ExpectedContentFingerprintSha256',([string]$pin.ContentFieldFingerprintSha256),
      '-TestId',$testId,
      '-DestinationPst',$destPst,
      '-DestinationFolderEntryId',$destFolderEntryId
    )
    & powershell.exe @workerArgs -Review
    if($LASTEXITCODE -ne 0){throw 'BW4g1 one-shot Review did not pass.'}

## Explicit operator-approved ONE Move

The operator already gave explicit approval for TEST PST one-shot Move.
Execute ONE time only after successful independent -Review result:

    $newReviewId=[guid]::NewGuid().ToString('D')
    $idx=[Array]::IndexOf($workerArgs,'-CandidateReviewId')
    if($idx -lt 0){throw 'Missing review argument.'}
    $workerArgs[$idx+1]=$newReviewId
    & powershell.exe @workerArgs -Execute -ConfirmOneShotDisposableMove
    if($LASTEXITCODE -ne 0){throw 'BW4g1 Move may be indeterminate. NEVER RETRY.'}

This controller performs:
1. Full BW4f3->BW4e2->BW4d/BW4c historical safety re-review.
2. Unique exact empty GUID-named disposable destination PST and folder.
3. Fresh direct+targeted Outlook MAPI fingerprint comparison.
4. Final direct MAPI confirmation BEFORE claim.
5. Write immutable per-user CreateNew/Flush(true) claim file at:
   %LOCALAPPDATA%\OutlookPOP3Archive-BW4g-Claims\fixture-<TestId>.json
6. Exactly ONE MailItem.Move to that disposable folder.
7. Return a destination EntryID (NOT independent durability proof).

Result status if the call returns:
  OneSyntheticMoveReturnedRequiresIndependentReconciliation

Never delete, replace or rename the claim to enable another execution.
A timeout, COM exception or crash after claim is indeterminate: STOP.
Preserve both PSTs, original journal and user-local claim. Next step
BW4h is independent source/destination read-only reconciliation.
