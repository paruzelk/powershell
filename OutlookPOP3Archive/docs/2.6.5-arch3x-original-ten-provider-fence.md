# ARCH3x — оригинальный MailMover: десять синтетических provider fences и проверка исходных Intent

**20 ноября 2026 года.** DEV / Windows PowerShell 5.1. Это первая часть будущего безопасного batch-10; никакого реального COM Move, PST или общего DuplicateIndex не изменяет. ARCH3s–ARCH3v уже завершены и повторения операторских проверок не требуют.

## Исправление обнаруженного дефекта предыдущего выпуска

Опубликованный Invoke-ARCH3w1.ps1 ссылался на несуществующий Core/Archive/ARCH3w1TenOriginalIntents.ps1. В новой ветке исправлена загрузка существующего Core/Archive/ARCH3w1SemanticPart2Intents.ps1; Pester предотвращает регрессию. Исторические RunId, witness и SHA не изменялись.

## Полный синтаксис

~~~powershell
.\Invoke-ARCH3x.ps1 -Mode Plan -RunId '093b5ce9-4a90-46fa-b6a5-7cdba61d2f15'
.\Invoke-ARCH3x.ps1 -Mode ReviewPrepared -RunId '<existing-RunId>' -SealSha256 '<ARCH3v-Seal-SHA>' -ManifestSha256 '<ARCH3w1-manifest-SHA>' -JournalSha256 '<ARCH3w1-journal-SHA>'
.\Invoke-ARCH3x.ps1 -Mode Synthetic [-Fault None|AfterClaim|AfterInvocation|ProviderThrows|AfterMoveReturned] [-FaultAt 1..10] [-WhatIf]
.\Invoke-ARCH3x.ps1 -Mode Inspect -Workspace '<OPA265-ARCH3x-SYNTH-guid under OS TEMP>'
~~~

| Параметр | Режимы и смысл |
| --- | --- |
| -Mode | Plan: только план без файлов/Outlook; ReviewPrepared: независимое чтение защищённых оригинальных десяти Intent; Synthetic: новые fake-only операции в OS TEMP; Inspect: только чтение синтетического состояния. |
| -RunId | Только Plan/ReviewPrepared и строго ранее зафиксированный GUID, не создавать новый. |
| -SealSha256 | Только ReviewPrepared, внешний исходный SHA ARCH3v Seal, 64 символа lowercase hex. |
| -ManifestSha256 | Только ReviewPrepared, SHA оригинального ARCH3w1 manifest. |
| -JournalSha256 | Только ReviewPrepared, SHA оригинального ARCH3w1 OperationJournal. |
| -Workspace | Только Inspect, каталог синтетической операции внутри OS TEMP. Никаких реальных путей PST. |
| -Fault | Только Synthetic: None, AfterClaim, AfterInvocation, ProviderThrows, AfterMoveReturned. По умолчанию None. |
| -FaultAt | Только Synthetic, номер 1..10, по умолчанию 4. |
| -WhatIf | Synthetic: отмена всех записей до создания каталога. |

## Команды для CI и локальной демонстрации

~~~powershell
.\Invoke-ARCH3x.ps1 -Mode Plan -RunId '093b5ce9-4a90-46fa-b6a5-7cdba61d2f15' | Format-List

$ok = .\Invoke-ARCH3x.ps1 -Mode Synthetic
$ok | Format-List
.\Invoke-ARCH3x.ps1 -Mode Inspect -Workspace $ok.Workspace | Format-List

$broken = .\Invoke-ARCH3x.ps1 -Mode Synthetic -Fault AfterInvocation -FaultAt 4
$broken | Format-List
.\Invoke-ARCH3x.ps1 -Mode Inspect -Workspace $broken.Workspace | Format-List
~~~

Успешный synthetic ожидает Claims=10, ProviderInvocations=10, Returned=10. Авария AfterClaim при FaultAt=4 даёт 4/3/3; AfterInvocation, ProviderThrows или AfterMoveReturned дают 4/4/3. Во всех случаях AutomaticMoveRetryAllowed=False.

## Архитектура и ограничения

Использованы исходные Core/Archive/MailMover.ps1, ARCH3c CreateNew/Flush(true) и ARCH3r ten source full semantic witness fixture. Новый original MailMover fake-only provider принимает только явно помеченные SyntheticOnly PSCustomObject, запрещает __ComObject, проверяет hash original claim и SourceEntryId/ArchiveEntryId/folder, сохраняет immutable Invocation ДО synthetic Mail.Move. Исходная ARCH3w1 Test-OPA265ARCH3w1PreparedReadback используется без модификации и только в ReviewPrepared.

Это не независимая реальная проверка Outlook и не разрешение на Move: WriterPermit=False, ProductionReady=False. Original ArchiveVerifier реальной партии, рестарт Outlook, Reconciled, DuplicateIndex и 90 ГБ production writer ещё не сертифицированы. Автоматический повтор, Resume и Auto запрещены для неопределённых результатов.
