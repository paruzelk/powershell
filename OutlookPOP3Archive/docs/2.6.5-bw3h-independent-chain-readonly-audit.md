## What BW3h does

Requires explicit -Review and native Windows PowerShell 5.1 STA.
No -Record, -Execute or -Move parameter is offered.

1. Rejects every unrelated RunId, source PST or journal SHA256 before
   accessing Outlook.
2. Reads and fingerprints **seven exact regular immutable evidence files**:
   original Intent journal; fixture request; fixture scope; Move attempt
   claim; dispatch claim; controller result; and independent BW3g1
   manual-size acceptance JSON.
3. Independently checks the original journal SHA256 and the *previously
   user-observed* acceptance JSON SHA256. Rejects reparse-point files.
4. Reruns the existing BW3g1 -Review, which in turn reruns BW3f, BW3e,
   BW3d, BW3b: native read-only Outlook profile and two mounted PSTs,
   exact EntryID and synthetic folders, source 0/archive 1, Body text
   including SPACE/CR/LF, attachment count 0, MAPI sizes, claims,
   journal and approval JSON schema and hashes.
5. Requires the precise BW3g1 Review schema, "record verified" status,
   exact original sha/accepted sha and strictly typed Boolean statuses.
   A "recorded" (write mode) result is never mistaken for verified.
6. Rehashes all seven immutable evidence files after read-only Outlook
   inspection; stops if any changes.
7. Outputs only an in-memory verdict:
   IndependentEvidenceChainVerifiedJournalDecisionPending
   with JournalReconciliationAuthorized=False and no write permit.

BW3h does NOT persist another file, reset/delete a claim, edit source
or archive PST, invoke MailItem.Move, append Reconciled/Completed,
invoke LIVE6a -Execute, call a production Worker, or retry anything.

## Decision boundary

An existing human-accepted size exception is **NOT** proof of full
MAPI item byte equality. We still do not know the instant when Outlook
added SPACE+CR+LF or why MAPI Size grew by eight. The original journal
remains ONE unresolved Intent and its SHA-256 must remain the same.

Even with BW3h PASS, a journal mutation requires a **new separate
explicit user authorization** and a further safety review of journal
protocol, one-shot constraints and exact original evidence. Do not
run any LIVE6a write command on the basis of BW3h.
