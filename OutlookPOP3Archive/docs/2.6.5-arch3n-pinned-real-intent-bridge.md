## Реализовано

`Get-OPA265ARCH3nPinnedRealRoute`: строго read-only чтение уже существующего ARCH3j protected Intent, оригинального журнала, полного ARCH3i witness и оригинального DuplicateIndex. Повторно вычисляет имена через original `Get-OPAArchivePartPath`, `Get-OPAArchiveTargetPath` и подтверждает единственную Part1, отсутствие Part2, 500 исходных записей. Любое расхождение или появление Part2 = STOP, НЕ создавать Part3 и НЕ повторять Prepare.

`Assert-OPA265ARCH3nSyntheticRealIntentBridge`: внутри синтетического исходного `Get-OPAArchiveDestination` (после проверок ARCH3m до вызова New-OPAArchivePst) сопоставляет exact real Intent/Journal/full witness/contract с fake year2020 route. Fake source EntryID должен быть равен **реальному pinned EntryID**, а расположение фейковой Part2 обязано отличаться от реальной. Возвращается только read-only объект диагностики, без токена допуска.

`Invoke-ARCH3n.ps1` предоставляет два режима: `Plan` без Outlook, `Audit` дополнительно повторно читает исходное MailItem через оригинальный ARCH3k live-read-only verifier. Никакие записи в существующие PST, journаl, index и evidence не производятся.

## Использование, Windows PowerShell 5.1 STA

```powershell
$pin = @{
    RunId = '9d276dc4-a0e6-4e74-891f-81502fafe7db'
    IntentSha256 = 'f0860d55c5939498094832a8b924dbca9b65532cf53f8234f4aeda97ab631a2b'
    JournalSha256 = 'a19f113a6454b1d17333c9a53fc22d065876754b9fbab3167087487d0b2b981e'
}
.\Invoke-ARCH3n.ps1 -Mode Plan @pin | Format-List
.\Invoke-ARCH3n.ps1 -Mode Audit @pin | Format-List
```

Для `Audit` запущен Outlook 2019 с исходным профилем Outlook. `Plan` не вызывает Outlook COM. В обоих случаях WriterPermit=False.

| Параметр | Тип | Значение |
| --- | --- | --- |
| `-Mode` | `Plan` или `Audit` | По умолчанию Plan. НЕТ Move, Seal, Prepare и Resume. |
| `-RunId` | GUID string | Строго закреплённый операцией ARCH3j ID. |
| `-IntentSha256` | lowercase SHA256 string | Строго исходный хэш защищённого ARCH3j PrepareIntent. |
| `-JournalSha256` | lowercase SHA256 string | Строго исходный хэш оригинального OperationJournal. |

Новый internal `-ARCH3nSyntheticRealIntentBinding` — объект только fake-only `Get-OPAArchiveDestination` под прежними ARCH3d+ARCH3l+ARCH3m. Любой вызов с этим объектом без синтетической сферы обязан завершиться исключением до доступа к PST.
