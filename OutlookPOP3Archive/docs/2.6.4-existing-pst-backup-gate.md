## New safety modules

Core/Worker/ExistingPstBackupGuard.ps1 rejects missing source files,
same path, destination inside the Outlook PST folder, UNC paths,
reparse points/junctions, existing backup/partial, and insufficient
local free space (source file size plus 128 MiB).

Core/Diagnostics/New-OPA264ExistingPstBackup.ps1 offers a no-write
Review mode. Creation requires -CreateBackup and the exact approval
token BACKUP-OPA264-EXISTING-PST, plus Outlook fully closed. It makes
a fresh .opa264-partial copy in a DIFFERENT directory, flushes the
bytes, compares exact lengths and SHA-256, then renames the verified
copy to the approved, previously nonexistent backup PST filename.
It never touches the original PST, existing archives, mail, Outlook
profiles or journals. A failed copy leaves the partial file as
evidence; do not mistake it for a valid backup.

Tests/Worker/ExistingPstBackup.Tests.ps1 adds 14 synthetic no-COM
tests. The backup script itself must be tested with a sacrificial PST
file before copying the actual 7.2 GB source.

## Operator sequence

1. Run exact-source Windows PowerShell 5.1 CI, target 478/35.
2. Choose a BACKUP folder on a fixed local drive with at least 7.3 GiB
   free, outside the current Outlook PST directory.
3. Create that folder manually, e.g.:
       New-Item -ItemType Directory -Path "$env:USERPROFILE\Downloads\OPA264-Backups" -Force
4. Preview only:
       $source = "$env:USERPROFILE\Documents\Файлы Outlook\info@stios.ru.pst"
       $backup = "$env:USERPROFILE\Downloads\OPA264-Backups\info@stios.ru.pre-264-live.pst"
       .\Core\Diagnostics\New-OPA264ExistingPstBackup.ps1 -SourcePst $source -BackupPst $backup -Review
5. Fully close Outlook, confirm OUTLOOK.exe is absent, then copy with
   an interactive confirmation:
       .\Core\Diagnostics\New-OPA264ExistingPstBackup.ps1 -SourcePst $source -BackupPst $backup -CreateBackup -ApprovalToken 'BACKUP-OPA264-EXISTING-PST' -Confirm
6. Preserve backup and report: Status=BackupCopySHA256Verified. Byte
   identity does NOT prove the backup can be restored in Outlook.
7. Restart SAME profile Outlook and preserve real Inbox, archives and
   all other folders. The future LIVE2 explicit opt-in test scope will
   create an isolated synthetic-only test folder and a separate
   run-unique destination PST.

This phase creates NO synthetic folder or MailItem yet and authorizes
