## Запуск (только тестовые POP3)

~~~powershell
.\OutlookPOP3Archive.ps1 -Mode Auto -ConfirmDevAutoArchive -Quiet -AutoDevMaxBatches 1 -WhatIf
$result = .\OutlookPOP3Archive.ps1 -Mode Auto -ConfirmDevAutoArchive -Quiet -AutoDevMaxBatches 1
$result | Format-List
Get-Content -LiteralPath $result.DiagnosticLog -Encoding UTF8
~~~

Quiet подавляет потоки предупреждений, verbose, debug и information у Auto; возвращает структурированный результат. Исключение остаётся ошибкой для интерактивного вызова. Для будущего планировщика отдельная **DEV-only** обёртка, запускаемая в отдельном Windows PowerShell 5.1 STA, без вывода при реальном запуске:

~~~powershell
powershell.exe -NoProfile -NonInteractive -STA -WindowStyle Hidden -File .\Invoke-OPAAutoDev.ps1 -ConfirmDevAutoArchive -AutoDevMaxBatches 1
$LASTEXITCODE
~~~

| Параметр | Default | Назначение |
|---|---|---|
| Quiet | False (обёртка True) | Приватный диагностический JSONL; структурированный результат сохраняется |
| AutoBatchDelaySeconds | 2 (0–300) | Пауза после подтверждённой партии перед следующей партией того же PST |
| AutoRecoveryDelaySeconds | 5 (5–300) | Начальная задержка Resume; удвоение до 300 сек, только при сохранённом pending |
| AutoLogRetentionDays | 30 (1–3650) | Удаление только завершённых успешных/ограниченных диагностических summary |
| AutoMaxResumeAttempts | 3 (1–10) | Существующий предел восстановления, не повтор Move |

Exit codes обёртки: 0 — исчерпано/нет POP3; 10 — безопасный лимит партии; 20 — blocked/partial с ошибками; 30 — исключение или неизвестный результат. Не настраивать внешние повторы по ненулевому коду до ARCH7g. WhatIf возвращает параметры без COM/discovery и записи.
