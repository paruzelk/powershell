# ARCH6f3a DEV — безопасные пропуски

Реальный ARCH6f3: 999/1000 verified/reconciled/indexed, 1 preclaim type 5 skip. Не повторять завершённые переносы. Continue по умолчанию; Stop останавливает после завершённой партии с пропуском. Неподдерживаемый тип/размер/число вложений, число получателей, длина имени и превышение явного лимита сообщения откладываются. Неизвестная ошибка, нестабильный/неудачный экспорт (может быть системным), очистка, маршрут, COM outcome, журнал/индекс останавливают работу. Никакого автоматического повторного Move. ProductionReady=False.

Отдельные неизменяемые ARCH6-deferred-<transaction>.jsonl находятся в каталоге OutlookPOP3Archive-Transactions. Они привязаны к PST, профилю и StoreID, создаются после исходной проверки и сверяются с полным планом и журналами перед последующим выбором. Не являются DuplicateIndex. Не удалять оригинальные журналы или ledger. Сокращённое окно SkippedItems не используется для новых записей. Нулевые партии требуют полного покрытия. MaxMessages считает verified, MaxBatches ограничивает последовательность.

## Запуск (Windows PowerShell 5.1 STA)

~~~powershell
$common=@{ProfileName='Outlook';SourcePst='C:\Users\bogoderov_e\Documents\Файлы Outlook\info@stios.ru.pst';ConfirmTestArchive=$true;ConfirmOutlookRestart=$true}
# Однократный импорт исторического пропуска, без Move; только после CI PASS:
.\Invoke-OPAArchiveBatches.ps1 @common -ImportDeferredTransaction '20261125-121521-9ea298fa'
# Только после успешного импорта:
.\Invoke-OPAArchiveBatches.ps1 @common -BatchSize 500 -MaxMessages 1500 -MaxBatches 5 -OlderThanMonths 60 -ArchiveGrouping YearQuarter -DisableArchivePstSizeLimit -WhatIf
# Для ограниченного реального теста убрать -WhatIf.
~~~

Импорт проверяет исходный завершённый checkpoint и оригинальный operation/step journal по текущему StoreID. Исторический профиль отдельно не записан; используется подтверждённый активный профиль. Импорт отдельно от Move. Исторический пропуск должен соответствовать точному сохранённому сообщению и плану. Ручной перенос отложенных писем возможен; автоматический повтор и автоматическое снятие отложенного статуса не реализованы.

Инвентаризация классов/вложений и CSV/HTML отчёты — отдельные инструменты; не участвуют в разрешении Move. Инвентаризация охватывает все папки, включая системные (это не разрешение их архивировать), год по ReceivedTime, без хеширования; Complete=False при ошибках чтения. CSV/HTML — исторический список, не подтверждение текущего местонахождения письма. Физический Compact не автоматизирован. CI синтетический, реальный тест требуется.

~~~powershell
$inv=.\Get-OPAArchiveMessageInventory.ps1 -SourcePst $common.SourcePst -ProfileName Outlook
$inv | Select-Object Folders,Items,Complete,Classes,MessageClasses,AttachmentTypes,Risks,RiskByYear | Format-List
~~~
