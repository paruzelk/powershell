# BW4k7v2a3 — read-only location of original failed pilot in Drafts

## Real evidence and API hypothesis

Original failed SuiteId: `2c15cb7c-4c09-4bcf-bca1-9fec458af3a5`.

- BW4k7v2a1 created and attached a new PST in the existing `Outlook` POP3 test profile, but the combined post-Save assertion failed.
- BW4k7v2a2 independent operator run passed **3419 Pester / 116 containers** and found the exact original disposable PST (271,360 bytes), exact one test folder and **zero mail items** there. Nine stores now attached, original `one-pilot-intent.json` exists with SHA256 `d78b80450f84e182fef7549bfae6cc48e1b487eb190e216cecbee7be9e05f606`; no sealed manifest.
- This does **not** prove the pilot was lost or where it went. Neither stage searched other stores for mail.
- **Microsoft Outlook API nuance:** [MailItem.Save](https://learn.microsoft.com/en-us/office/vba/api/outlook.mailitem.save) says a *new* mail item is saved in the default folder for that item type, while [Items.Add](https://learn.microsoft.com/en-us/office/vba/api/outlook.items.add) constructs an item in a target folder collection. The fact that target `Folder.Items.Add('IPM.Note')` was used before `Save()` therefore does not by itself prove the first persisted location.
- [Store.GetDefaultFolder(olFolderDrafts)](https://learn.microsoft.com/en-us/office/vba/api/outlook.store.getdefaultfolder) accesses a store-specific Drafts folder; `olFolderDrafts=16`. By contrast, `NameSpace.GetDefaultFolder` would address the profile's default store and may create a missing default folder. The diagnostic deliberately uses `Store.GetDefaultFolder(16)` **only**.

## Read-only Stage BW4k7v2a3

New `Core/Diagnostics/Invoke-OPA265BW4k7v2a3FindOriginalPilotDraftsReadOnly.ps1`:

- Uses the **original failed SuiteId** and requires the known, verified `ExpectedIntentSha256` before opening Outlook.
- Validates the current profile `Outlook`, account `info@stios.ru` with POP3 AccountType=2, original delivery StoreID and the unique existing test PST path. The old PST must already be attached (no auto-mount).
- Visits at most 32 existing store descriptors, calls each `Store.GetDefaultFolder(16)`, and `Items.Restrict("[Subject] = '<exact controlled synthetic subject>'")`. Does **not** enumerate mail in Inbox, Sent, Deleted, custom folders, etc. It does not open the content of unrelated mail.
- Inspects at most 8 exact-subject candidates per Drafts folder (at most 16 total). For matches, reads only Class, Subject, EntryID and Parent folder/store identity, and optionally cross-checks by `GetItemFromID` for that exact matching item.
- A provider exception or an exceeded match bound is reported as incomplete; does **not** claim no mail was found. Missing Drafts folder is reported separately.
- The report is **in memory only** and does not mutate PST/profile/messages/evidence. No `AddStoreEx`, `Save`, `Move`, `Delete`, `Send`, Outlook restart or retry of the original `CreatePilot`.
- The result does not claim actual previous Save destination was proven historically; only currently observed exact matches. Other folders are not searched.

## Operator commands

From the freshly extracted standalone **BW4k7v2a3** DEV ZIP project directory, use native Windows PowerShell 5.1 STA while Outlook is already running in the same `Outlook` profile:

    .\Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'

    $suite = '2c15cb7c-4c09-4bcf-bca1-9fec458af3a5'
    $originalIntentSha = 'd78b80450f84e182fef7549bfae6cc48e1b487eb190e216cecbee7be9e05f606'
    $script = '.\Core\Diagnostics\Invoke-OPA265BW4k7v2a3FindOriginalPilotDraftsReadOnly.ps1'

    & $script -Mode Plan -SuiteId $suite | Format-List

    $review = & $script -Mode Review -SuiteId $suite -ExpectedIntentSha256 $originalIntentSha

    $review | Select-Object Status, SuiteId, ExistingStoresChecked, DraftsFoldersWithReadableSearch, ExactPilotSubjectMatches | Format-List
    $review.StoreChecks | Format-Table StoreIndex, IsProfileDefault, IsPop3Delivery, IsOriginalTestPst, DraftsStatus, DraftsItemCount, RestrictedSubjectMatchCount -AutoSize
    $review.PilotMatches | Format-List *
    $review.Diagnosis | Format-List *
