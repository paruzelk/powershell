## POP3-SCOPE-001-BW4k7q-v1

Input: the exact existing BW4k7p **structure-only** read-only POP3 DeliveryStore folder inventory. Namespace/Account/DeliveryStore uniqueness and StoreID have already been checked by that existing live controller. Scope policy itself is pure, in-memory, and never opens Outlook or mutates files.

Rules:
1. Include exact default POP3 Inbox by Store.GetDefaultFolder(6) EntryID, exact default POP3 Sent Items by Store.GetDefaultFolder(5) EntryID, and mail-type user folders and their descendants. Include Sent even if it has zero mail. Synthetic tests also confirm a nonempty Sent fixture with 37 mails is included; NO real Sent messages are created.
2. Exclude exact default POP3 Outbox by Store.GetDefaultFolder(4) EntryID. Never confuse it with Sent. Exclude previously verified system/default folders and nonmail folders.
3. Quarantine (exclude from proposed archive scope, but NEVER delete) only tightly matching root synthetic test folders OPA264-LIVE3-[32 hex] and OPA265-BW*/LIVE*-[32 hex], and their descendants. An arbitrary folder with a similar prefix but invalid hex ID is not excluded automatically.
4. Exclude exactly two observed root settings folders in the user's locale: \Настройка действий беседы and \Настройка быстрых действий. These are NOT enumerated by Microsoft OlDefaultFolders and we do not invent MAPI default IDs. If either contains items, flag explicit NeedsManualReview; still no deletion or archiving.
5. Enforce unique root/Inbox/Sent/Outbox EntryIDs, true exact POP3 delivery-store verification, no IMAP message inspection, unique folder path/EntryID, real ancestor/role/depth, stable positive source PST size and strict eligible/excluded count reconciliation. Any missing or mismatching proof is STOP, no repair or production waiver.

Expected with unchanged operator PST counts: 22 folders, 7 LIVE3 test roots quarantined, 2 test messages quarantined, 2 special settings folders excluded, 26605 proposed POP3 eligible items (Inbox), 4 excluded items (2 Drafts + 2 test), POP3 Sent included but currently empty.

This is only a *candidate* logical folder scope. ProductionReady=False, WriterPermit=False, AutomaticRetryAllowed=False. Previous unknown PR_MESSAGE_FLAGS 0x00010000 (BW4k7o SEM-001) remains BLOCKED. This stage neither scans all items by year nor validates attachment bytes or PST physical durability.
