# 2.6.3 — Interrupted Move Reconciliation (DEV)

## Safety boundary

The independent `Core/Archive/MoveReconciliation.ps1` module never moves a message, writes Reconciled, creates/mounts a PST or permits automatic retry. It is not invoked by Archive, Resume or Auto. The Worker MailMove operation remains unavailable.

## Persisted evidence

2.6.3 extends MailMove Intent fields with SourceEntryId, SourceStoreId, SourceFolderPath, ArchivePst, TargetFolderPath, InternetMessageId, Subject, Sender and Size. Old 2.6.2 journals remain readable but an incomplete intent yields InsufficientEvidence. Journal SHA-256, sequence and transaction integrity are verified before analysis.

## Read-only classification

Full folder scans verify actual StoreID and folder paths, archive PST identity and four fingerprint fields. A failed COM property/collection read or incomplete fingerprint invalidates that snapshot.

| Status | Meaning |
|---|---|
| DestinationCandidate | Exactly one matching archive message, none in recorded source folder; **not proof** |
| SourceOnly | Match only in source; no automatic retry |
| BothPresent | Potential copy/duplicate; stop |
| MissingBoth | Cannot locate message; stop |
| Ambiguous | Multiple matching fingerprints; stop |
| IdentityConflict | EntryId/fingerprint conflict; stop |
| ScopeMismatch | Folder, store or archive path differs from Intent |
| IncompleteScan | Scan failed or inventory incomplete |
| UntrustedJournal | Truncated journal tail; preserve records |
| InsufficientEvidence | Old or metadata-poor Intent |
| AlreadyTerminal | Already confirmed in journal; no second action |

Every result has `ProvenMoved=False`, `AutomaticRetryAllowed=False`, `RequiresManualReview=True`. Source-only or destination-only observations never justify an automatic second Move or journal completion.

## Verification

Run `Invoke-CI.ps1 -ExpectedBuild '2.6.3-PREVIEW1'` under Windows PowerShell 5.1. Tests use fake source/destination COM folders and exercise identity/fingerprint/scan failures without modifying Outlook. Real integration needs disposable PSTs and a reviewed, separate approval protocol before any Worker Move is enabled.
