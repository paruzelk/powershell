## What the new stage does

`Core/Diagnostics/Invoke-OPA265BW4k7v2a6ReadOnlyBodyReview.ps1` has **only Plan and Review**.

- Strictly pinned original SuiteId and SHA-256 of original one-shot `create-intent.json` (operator independently observed this SHA).
- Same existing Outlook profile `Outlook`, original POP3 account `info@stios.ru` and its pinned delivery StoreID. Reads only the exact original default Drafts folder; never any other mailbox message content.
- Requires exact already-mounted original disposable PST/test folder still empty; **never auto-attaches PST** or touches older fixtures. Rejects unexpected preMove manifest, Move claim or Move return observation files.
- Bounded at most 16 default Drafts subjects to locate exactly one test Subject, confirms `Class=43`, `EntryID`, `StoreID`, `FolderID`, uniqueness via `Items.Restrict` and then reopens that **same synthetic** via `NameSpace.GetItemFromID`.
- Only for this exact synthetic message, reads `MailItem.Body` twice and compares with deterministic expected literal from BW4k7v2a4 layout. Computes original/actual SHA-256 of UTF-8 Body, UTF-8 byte lengths, UTF-16 code-unit lengths, counts of CRLF/lone LF/lone CR, common prefix length, and flags for line-ending-only, trailing-whitespace-only, appended non-whitespace suffix, truncation and other changes.
- **Does not output real Body, HTMLBody, raw suffix, email signature, real mailbox message body or any excerpts.** Even if actual body appears to contain a signature, it is treated as opaque personal data.
- Compares both MAPI read fingerprints to detect differences *between observed reads* (not a guarantee of physical disk persistence). Exact logical Body match cannot prove the historical moment after Save and never permits Move for the old SuiteId.
- No `Save`, `Move`, `Send`, `Delete`, `AddStoreEx`, registry write, PST/file write, automatic retry, source cleanup or production archive worker.
- Any mismatch, even mere CRLF normalization or trailing spaces, remains **SEM-001 UNACCEPTED**. No waiver of raw `PR_MESSAGE_FLAGS`.

```powershell

    ExactOriginalSyntheticSubjectCount, TargetFolderItems, BodyFormat,
```

Return the three *Evidence/Assessment* outputs. They disclose **only numeric/fingerprint diagnostics**, not the real Body or signature. Do not open, alter or forward private drafts to diagnose this.
